# 自己投資の重要性を説くポストの知識

出典：ポスト作成テンプレ教材「Type07：自己投資の重要性を説くポスト」の画像5枚（コンセプト解説1枚＋自己投資マインド不足の解説1枚＋構成解説1枚＋損失回避の解説1枚＋実例注釈1枚）を、今後ポストを書く際に再利用できる知識として整理したもの。

## 目的

**「お金を使って知識やスキルを得て、成功への道のりをショートカットすることの大切さ」**を伝えること。読者の中にある「自己投資マインドがない」状態——できるだけ無料情報で成功したい、独学でやるのが正義、という思い込み——を、「早く知識を得て成長したい」という自己投資マインドへ転換させるのが狙い。この転換ができていないと、いざ自分が商品を出したときに買ってくれる人が少なくなる、という実務的な理由も背景にある。

## 構成

前提として、読者には次のような「自己投資マインドがない」思い込みがある。

- できるだけ無料情報で成功したい…
- 無料で情報が手に入って当然…
- 独学でやるのが正義…

これを、次のような思考に転換させることを目指す。

- 目指す思考：「早く知識を得て成長したい！」
- 避けたい思考：「コンテンツなんて詐欺じゃない！？」

技法は2つある。

1. **自己投資してる様子を見せる**
   - 自分が自己投資してる様子を見せる
   - 第三者が自己投資して成功した様子を語る
2. **自己投資のメリットを語る**
   - 知識をつけることで成功への時間や手間を短縮できる
   - 知識や環境に投資する重要性を語る

さらに、これを具体的なエピソードに落とし込む型として「**自己投資をケチって失敗した話／自己投資をして得した話**」がある。

- 自分の経験談や体験談
- 第三者の事例
- 機会損失の話

この技法の背景には**損失回避**という行動原則がある。**「人間は得をするためのパワーよりも、損失を避けるためのパワーの方が強い」**——つまり「自己投資するとこれだけ得する」より「自己投資しないとこれだけ損する（機会損失）」という語り口の方が、行動を動かす力が強い。

実例では次の流れで構成されている。

1. **損失回避を刺激**：現状維持は衰退である、置いていかれたくない、という前提を提示する。
2. **自己投資してる様子**：具体的な金額と、それに対する価値観をセットで見せる。
3. **向上心を見せる**：ここで止まらない、まだまだ突っ走る、という姿勢を語る（`skills/empathy_post.md`の技法3と接続）。
4. **反応をとる**：「一緒に頑張る」人向けのCTAを添える。
5. **画像をつける**：実際に購入した教材・記事のスクリーンショットを証拠として添える。

## 書き方

- **自己投資マインドがない思い込みを先に言語化する**：「無料で情報が手に入って当然」のように、`skills/problem_post.md`と同じ技法で読者の思い込みを先回りする。
- **自己投資してる様子は金額と価値観をセットで見せる**：「今月も10万円ほど教材に課金済み」という金額の提示に加え、「稼いで貯金残高だけ増えても中身の人間が分厚くなってないと意味がない」のような価値観を添えると、単なる自慢ではなく信念の表明として伝わる。
- **メリットは「時間・手間のショートカット」というフレーミングで語る**：Type07自体のキャッチコピー「お金を使って知識やスキルを経てショートカットする大切さ」に対応させる。
- **損失回避を軸にする方が効果が高い**：メリット訴求より、「やらないことによる機会損失」を強調する方が読者の行動を動かしやすい。
- **自己投資の証拠として購入画面・教材のスクリーンショットを添える**：`skills/reproducibility_post.md`・`skills/action_post.md`の社会的証明の技法と同じ。
- **締めは向上心＋反応をとるCTAで終える**：「ここで止まるわたしではない」のような一言の後に、「一緒に頑張る！って人はいいねください」のようなCTAを添える。

## テンプレート

### 基本テンプレート（損失回避→自己投資の様子→向上心→CTA）
```
[現状維持・自己投資しないことへの警鐘を一文で]

最近は[脅威となる他者の動きを一言]

[読者の思い込みを代弁する一言]
（例：置いていかれたくはないし"現状維持は衰退"だと本気で思ってるので）

今月も[具体的な金額]ほど[何に]課金済み。

[自己投資に対する価値観の一言]
（例：たくさん稼いで貯金残高だけ増えても中身の人間が分厚くなってないと意味がない）

自分の"脳ミソ"にこれでもかというくらい投資していきます。

[取り組みを始めてからの解像度の変化を一言]

ここで止まるわたしではないので、まだまだ突っ走ります。

「一緒に頑張る！」って人は"いいね"くださいナ

[自己投資の証拠となる画像（購入した教材のスクショ等）を添える]
```

### 損失回避型エピソードテンプレート
```
自己投資をケチって失敗した話をするとするなら、
[過去に自己投資しなかったことで生じた具体的な機会損失]

逆に自己投資をして得した話をするとするなら、
[自己投資したことで得られた具体的な成果]

人間は得をするパワーよりも、
損失を避けるパワーの方が強いっていうから、

[読者に向けた損失回避の一言]
```

## 注意点

- **自己投資を煽りすぎない**：「独学は正義ではない」という主張が強すぎると、無料学習や独学そのものを一方的に否定するメッセージになりかねない。有料の学びが有効な場面を誠実に語る範囲にとどめる。
- **金額を誇張しない**：`skills/change_post.md`・`skills/problem_post.md`と同様、実際の金額のみを使う。
- **証拠画像の個人情報に配慮する**：購入画面・教材のスクリーンショットを見せる際、金額や個人情報が過度に露出しないよう加工する。
- **損失回避フレーミングは`skills/action_post.md`の「機会損失フレーミング」と技法的に重なる**：使う際は、誇張・虚偽の緊急性を作らないという同じ注意点が適用される。
- **`identity/my_offer.md`・`skills/my_position.md`・`skills/values.md`を踏まえる場合**：`skills/my_position.md`の押し出す価値観「短期的な利益より長期的な資産」「再現性のある仕組みを作る」からは、自己投資のメリットを「知識を長期的な資産として積み上げる」という文脈で語ると整合する。一方、「置いていかれたくない」という焦燥感を煽る表現は`skills/values.md`の落ち着いたトーンとは相性が悪いため、慌てさせるトーンよりも、淡々と「学び続けている」という向上心の描写にとどめる方がこのプロジェクトの声には合う。
