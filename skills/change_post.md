# 変化を見せるポスト（Before/After型）の知識

出典：ポスト作成テンプレ教材「Type01：変化を見せるポスト」の画像8枚（構成解説3枚＋実例注釈2枚＋どん底状態の描き方1枚＋実例注釈1枚＋POINTまとめ1枚）を、今後ポストを書く際に再利用できる知識として整理したもの。

## 目的

ビフォーアフター（変化前→変化後）を描くことで、読者に「〇〇さんみたいになりたい」という憧れ・欲求を引き起こし、フォローや商品購入などの行動につなげること。単なる実績アピールではなく、読者が自分の未来を重ね合わせられる"物語"として提示するのが狙い。

## 構成

「変化」には必ず前（Before）と後（After）があり、この対比構造が骨格になる。

1. **変化前（Before）**：どん底・ストレス状態。「現在の読者」または「過去の自分」の視点で描く。
2. **転換点**：何をして変わったのか（行動・気づき）を一言で挟む。
3. **変化後（After）**：理想の状態。「現在の自分（＝未来の読者）」の視点で描く。

実例（注釈付き投稿）では、この基本構造にさらに次の要素を足して説得力を積み上げている。

- **問題点の指摘**：読者が持っていそうな思い込みをあえて言語化して提示する（例：「新商品を毎月出さないと生き残れない」という固定観念）
- **金銭面での理想**：具体的な金額を提示する
- **ライフスタイルの理想**：時間の自由・過ごし方を描写する
- **イメージをリアルにする素材**：実際の写真を添えて実在感を出す
- **再現性の提示**：「自分だから」ではなく「誰でも」できることを明言する
- **画像で訴求**：入金画面・通知一覧など客観的な証拠を見せる
- **CTA**：末尾で「いいね」などの反応を求める

さらに複数の実例を見比べると、**変化前（Before）の描き方には2種類のパターンがある**ことが分かる。

1. **単一の感情的などん底描写**：「動物看護師として週5で14時間働いても15万円しか自由に使えるお金がなかった…」のように、辛い状況を一文で情景として描く型。
2. **客観的な属性・スペックの提示**：「偏差値38、最終学歴専門卒、2年前まで手取り15万円の動物看護師」のように、感情を語らず事実・属性を淡々と並べる型。数字や肩書きで「低い状態」を示すことで、後に続く実績とのギャップを際立たせる。

どちらも変化後（After）とセットで使うが、1は共感を、2はギャップによる説得力（属性は平凡なのに結果はすごい、というロジック）を狙っている点が異なる。

## 書き方

- **変化前は感情とセットで描く**：「自分にはできない」という拒絶感や、「ポストしてもいいね0だし、全然稼げない。もうやめようかな…」のような具体的な失敗エピソードを添えると、読者が自分ごと化しやすい。状態の説明だけでなく、そのときの感情を必ず一緒に書く。
- **変化後は切り口を絞って描く**：理想の状態を表す切り口には、金銭面／人間関係／恋愛／ライフスタイル／健康／時間的な余裕／ストレスなどがある。1投稿で全部盛り込むと薄まるので、テーマに応じて1〜2個に絞る。
- **接続詞で変化を強調する**：「こんな悲惨な過去でした…でも行動を変えたことで、こんな理想の状態になれました！」のように「でも／ですが」で変化前と変化後を明確に区切ると、落差が伝わりやすい。
- **リアルな証拠を添える**：実際の写真やスクリーンショット（入金画面・通知一覧など）を使うと、テキストだけの主張より信憑性が上がる。「画像を使って視覚的に訴求する」のは教材でも独立したPOINTとして強調されている。
- **再現性の一言を入れる**：「実はこれ、私だからできたわけではなく誰でも再現可能」という一文は、読者の「自分には無理」という壁を崩すために機能する。事実として言える場合のみ使う。
- **「雑魚な過去」を列挙してどん底状態に厚みを持たせる**：辛い状態の描写だけでなく、「検討したけど選ばなかった弱い選択肢」を会話調で複数並べると、どん底状態からの試行錯誤がリアルに伝わる（例：「Uber eatsは暑い日出来なさそうだし…」「ブログ？わたし文章書けないし…」「チャットレディ？怪しそう」）。1つの失敗ではなく、複数の逡巡を見せることで「自分もそうやって迷ってきた」という共感を誘う。
- **どん底状態を客観的な属性で描く場合は数字・肩書きで示す**：偏差値・学歴・給料などの客観的な事実を淡々と並べ、感情を挟まずに"低さ"を示す。その後に続く実績とのギャップそのものが説得材料になるため、無理に悲壮感を演出しなくてよい。
- **切り口はHARM（Health＝健康／Ambition＝将来・野心／Relation＝人間関係／Money＝お金）で考える**：教材では「ライフスタイルはどうか？」「健康面ではどうか？」「時間面ではどうか？」のように、複数の生活領域を横断してチェックすることが推奨されている。1つの切り口に詰まったら、HARMの各観点に当てはめて別の切り口を探す。
- **感情や価値観を必ず盛り込む**：事実の羅列だけで終わらせず、そのときどう感じたか・何を大事にしているかを一言添える。そのうえで、それが自分のMyペルソナ（どんな人物として見られたいか）やMyポジション（押したい手法・価値観）とズレていないか確認する。一貫性が崩れると読者の教育が積み上がらない（`skills/education.md`参照）。

## テンプレート

### 基本テンプレート（シンプル版）
```
[変化前の状態を感情とセットで一文]
（例：ポストしてもいいね0だし、全然稼げない。もうやめようかな…そう思った時期もありました。）

ですが、[転換点となった行動を一言]

[変化後の理想の状態を、切り口を1〜2個に絞って描写]
（例：金銭面／ライフスタイル／時間的な余裕 のどれかを選ぶ）

実はこれ、私だからできたわけではなく誰でも再現可能なタネも仕掛けもあるんですよね

[CTA]（例：気になる場合は迷わず"いいね"ください）
```

### 拡張テンプレート（実例ベース・要素をフル活用する版）
```
[見出し的なキャッチコピー]

今月（今回）は[何をしたか]、そこから[金銭面での理想を具体的な数字で]

[読者が持っていそうな思い込みを問題点として指摘]
「〇〇しないと△△できない…」
「でも〇〇のネタもないし、ずっとこのままなの？」
ということ。

結論…
[ライフスタイルの理想を描写]
（例：たった1日の作業で会社員の3ヶ月分を稼げる／自然の中で愛犬と散歩できる）

[実際の写真を添える]

実はこれ、私だからできたわけではなく誰でも再現可能なタネも仕掛けもあるんですよね

「気になる」という場合は迷わずポチッと"いいね"ください
[証拠となる画像（入金画面など）を添える]
```

### 「雑魚な過去」列挙型テンプレート（Beforeに厚みを持たせる版）
```
[どん底状態を一文で]
（例：〇〇として週5で△△時間働いても、□□円しか自由に使えるお金がなかった…）

それが嫌で[改善策]についてたくさん調べ、

「[検討した選択肢1]は〇〇だし…」
「[検討した選択肢2]？わたし〇〇できないし…」
「[検討した選択肢3]？怪しそう」

といろんな[選択肢]を見て
やっとたどり着いた今の[今の手段]。

[今の手段]で気が向いた時に気の向くままにやってるだけで
[変化後の理想の状態を具体的な数字で]

もっと早くこの世界に出会いたかったよ
```

### 客観属性提示型テンプレート（どん底を数字・肩書きで示す版）
```
【[現在の実績を表す数字]】

これが[客観的な属性1（例：偏差値〇〇）]、
[客観的な属性2（例：最終学歴〇〇）]
[〇年前まで〇〇円の△△だった、どこにでもいる人]の[現時点]での収入でぷ

これまで[支えてくれた人・出来事]があってここまで来れたなぁと、しみじみしております…

さて、[次にやること・今の姿勢を一言]
```

### 視覚的訴求チェック（POINTまとめ）
投稿を書き終えたら、次の3点を確認する。
- 画像（写真・スクリーンショット）で視覚的に訴求できる要素はないか
- HARM（健康／将来・野心／人間関係／お金）のどの切り口で書いているか意識できているか
- 感情や価値観が入っており、Myペルソナ・Myポジションと一貫しているか

## 注意点

- **Beforeを描きすぎない**：どん底状態を誇張しすぎると読者を不快にさせたり、痛々しく見えたりするリスクがある。共感を得られる範囲にとどめる。
- **数字・証拠は事実に基づくこと**：変化後の実績・金額は誇張しない。証拠画像を使う場合は、氏名や口座番号など個人情報が映り込まないよう加工する。
- **切り口を詰め込みすぎない**：金銭面・人間関係・恋愛…と欲張って全部盛り込むと訴求が散漫になる。テーマを1〜2個に絞る。
- **「誰でも再現可能」は事実がある場合のみ使う**：再現性がないのに使うと、過大な期待を持たせて信頼を損なうリスクがある。
- **学歴・偏差値ネタは扱いに注意する**：客観属性型でどん底状態を描く際、偏差値や学歴を「低い」ものとして扱う表現は、自分自身のことであっても学歴差別的なニュアンスに読めてしまう場合がある。自虐のトーンが行き過ぎて他の同じ背景の読者を傷つけないか確認する。
- **HARMは切り口探しの補助であり、無理に全部使わない**：健康・将来・人間関係・お金のどれか1〜2個に絞る。詰め込むと基本テンプレート同様に散漫になる。
- **他のスキル・資料との住み分け**：
  - `skills/education.md`（現状維持マインド→成功者マインドの教育構造）とは、狙いが「思考・価値観の変化」である点で異なる。こちらは「感情の変化（憧れ）」に特化。
  - `skills/content-seller-post-writer/references/patterns.md` の「逆境ストーリー系」パターンとも重なるが、そちらはペルソナの背景ストーリー全体を語る形式。この資料はBefore/Afterの対比構造そのものの設計に特化した、より汎用的な型として使う。
