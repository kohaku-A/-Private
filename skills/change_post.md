# 変化を見せるポスト（Before/After型）の知識

出典：ポスト作成テンプレ教材「Type01：変化を見せるポスト」の画像5枚（構成解説3枚＋実例注釈1枚＋どん底状態の描き方1枚）を、今後ポストを書く際に再利用できる知識として整理したもの。

## 目的

ビフォーアフター（変化前→変化後）を描くことで、読者に「〇〇さんみたいになりたい」という憧れ・欲求を引き起こし、フォローや商品購入などの行動につなげること。単なる実績アピールではなく、読者が自分の未来を重ね合わせられる"物語"として提示するのが狙い。

## 構成

「変化」には必ず前（Before）と後（After）があり、この対比構造が骨格になる。

1. **変化前（Before）**：どん底・ストレス状態。「現在の読者」または「過去の自分」の視点で描く。
2. **転換点**：何をして変わったのか（行動・気づき）を一言で挟む。
3. **変化後（After）**：理想の状態。「現在の自分（＝未来の読者）」の視点で描く。

実例（注釈付き投稿）では、この基本構造にさらに次の要素を足して説得力を積み上げている。

- **問題点の指摘**：読者が持っていそうな思い込みをあえて言語化して提示する（例：「新商品を毎月出さないと生き残れない」という固定観念）
- **金銭面での理想**：具体的な金額を提示する
- **ライフスタイルの理想**：時間の自由・過ごし方を描写する
- **イメージをリアルにする素材**：実際の写真を添えて実在感を出す
- **再現性の提示**：「自分だから」ではなく「誰でも」できることを明言する
- **画像で訴求**：入金画面など客観的な証拠を見せる
- **CTA**：末尾で「いいね」などの反応を求める

## 書き方

- **変化前は感情とセットで描く**：「自分にはできない」という拒絶感や、「ポストしてもいいね0だし、全然稼げない。もうやめようかな…」のような具体的な失敗エピソードを添えると、読者が自分ごと化しやすい。状態の説明だけでなく、そのときの感情を必ず一緒に書く。
- **変化後は切り口を絞って描く**：理想の状態を表す切り口には、金銭面／人間関係／恋愛／ライフスタイル／健康／時間的な余裕／ストレスなどがある。1投稿で全部盛り込むと薄まるので、テーマに応じて1〜2個に絞る。
- **接続詞で変化を強調する**：「こんな悲惨な過去でした…でも行動を変えたことで、こんな理想の状態になれました！」のように「でも／ですが」で変化前と変化後を明確に区切ると、落差が伝わりやすい。
- **リアルな証拠を添える**：実際の写真やスクリーンショット（入金画面など）を使うと、テキストだけの主張より信憑性が上がる。
- **再現性の一言を入れる**：「実はこれ、私だからできたわけではなく誰でも再現可能」という一文は、読者の「自分には無理」という壁を崩すために機能する。事実として言える場合のみ使う。

## テンプレート

### 基本テンプレート（シンプル版）
```
[変化前の状態を感情とセットで一文]
（例：ポストしてもいいね0だし、全然稼げない。もうやめようかな…そう思った時期もありました。）

ですが、[転換点となった行動を一言]

[変化後の理想の状態を、切り口を1〜2個に絞って描写]
（例：金銭面／ライフスタイル／時間的な余裕 のどれかを選ぶ）

実はこれ、私だからできたわけではなく誰でも再現可能なタネも仕掛けもあるんですよね

[CTA]（例：気になる場合は迷わず"いいね"ください）
```

### 拡張テンプレート（実例ベース・要素をフル活用する版）
```
[見出し的なキャッチコピー]

今月（今回）は[何をしたか]、そこから[金銭面での理想を具体的な数字で]

[読者が持っていそうな思い込みを問題点として指摘]
「〇〇しないと△△できない…」
「でも〇〇のネタもないし、ずっとこのままなの？」
ということ。

結論…
[ライフスタイルの理想を描写]
（例：たった1日の作業で会社員の3ヶ月分を稼げる／自然の中で愛犬と散歩できる）

[実際の写真を添える]

実はこれ、私だからできたわけではなく誰でも再現可能なタネも仕掛けもあるんですよね

「気になる」という場合は迷わずポチッと"いいね"ください
[証拠となる画像（入金画面など）を添える]
```

## 注意点

- **Beforeを描きすぎない**：どん底状態を誇張しすぎると読者を不快にさせたり、痛々しく見えたりするリスクがある。共感を得られる範囲にとどめる。
- **数字・証拠は事実に基づくこと**：変化後の実績・金額は誇張しない。証拠画像を使う場合は、氏名や口座番号など個人情報が映り込まないよう加工する。
- **切り口を詰め込みすぎない**：金銭面・人間関係・恋愛…と欲張って全部盛り込むと訴求が散漫になる。テーマを1〜2個に絞る。
- **「誰でも再現可能」は事実がある場合のみ使う**：再現性がないのに使うと、過大な期待を持たせて信頼を損なうリスクがある。
