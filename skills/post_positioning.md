# ポジションをとるポストの知識

出典：ポスト作成テンプレ教材「売上につながるポスト7つの要素」の①「ポジションをとるポスト」を掘り下げた画像3枚（コンセプト解説1枚＋実例注釈1枚＋実例注釈2種）を、今後ポストを書く際に再利用できる知識として整理したもの。

この資料は`skills/post_principles.md`で挙げた7要素のうち1番目「ポジションをとるポストをする」の詳細版にあたる。他の6要素（エンゲージメント、導線、リアルタイム性、Myコンセプト、一文目のフック、共通言語）は`skills/post_principles.md`を参照。

## 目的

**「専門家としてポストをする」**ことで、コンテンツが売れる状態を作ること。ただ「行動しなさい」「自己投資しなさい」というような一般論を発信するだけでは、専門家としてのポジションが確立されておらずコンテンツは売れない。特定分野における専門家としての立場を明確にすることで、初めて発信に説得力が伴い、商品が売れるようになる。

## 構成

ポジションをとるポストの核は、**単なる一般的な発信ではなく、自分が強いニッチな専門分野を明示すること**。

例：「ぽにょ＝非稼ぐ系での運用にも強い発信者＝単なるビジネス知識ではなく非稼ぐ系運用のコツも発信」——ビジネス全般ではなく、「非稼ぐ系」という具体的なニッチに強い発信者、というポジションを明確に打ち出している。

**重要な注意点（POINT）**：ポジションを取るポストは専門性が高くなりやすく、その分「内容が難しくなる」というトレードオフがある。これを解消するために、**初心者でも理解しやすい具体的な情報（実例・画像）を必ずセットで使う**ことが推奨されている。

実例を見ると、専門家ポジションの見せ方には2つのアプローチがある。

1. **専門分野の中で具体的なテンプレ・切り口を複数列挙する**：例えば「非稼ぐ系運用」の専門家として、イベント（クリスマス・正月等）に紐づけた投稿の切り口を、恋愛系・ダイエット系・美肌系など複数ジャンル分まとめて提示する。
2. **特定ジャンルの攻め方を実例付きで解説する**：例えば「サウナは売りづらい」という定説に対して、HSP界隈・肩こり界隈・スキンケア界隈など複数の切り口を提示し、漫画やマインドマップの画像を添えて具体性を補強する。

## 書き方

- **一般論で終わらせず、自分が強いニッチな専門分野を明示する**：「ビジネス」ではなく「非稼ぐ系運用」のように、具体的なニッチを言語化する。
- **専門性の高い内容は具体例で必ず補う**：POINTにある通り、専門性が上がるほど内容は難しくなるため、初心者にも伝わる具体例・テンプレ・画像をセットにする。
- **実例はテンプレ・切り口の集合として複数列挙する**：1つの例だけでなく、恋愛系・ダイエット系・美肌系のように複数ジャンル分のテンプレを並べると、具体性と網羅性が両立する。
- **画像（漫画・マインドマップ等）で具体性を補強する**：テキストだけでは伝えにくい切り口の全体像を、図解や実例画像で見せると理解が早まる。
- **専門分野内でもさらに切り口を変える**：同じ専門分野（例：サウナ）でも、ターゲットとなる界隈（肩こり界隈、スキンケア界隈等）を変えることで、複数の読者層にリーチできることを示す。
- **情報提供だけで終わらせず、行動・反応を促す一言を添える**：「ちゃんと実践してな」「成果報告待ってるで」のように、読んだ後の行動を軽く促す。

## テンプレート

### 基本テンプレート（専門家ポジション表明→具体例集）
```
[専門分野]で戦いたい人必見。

[専門分野]のコンテンツを作る時に、
[具体的なツール・切り口]がガチでおすすめ。

[理由・詳細説明]

「[切り口テンプレ1]」とかでも書けそう
「[切り口テンプレ2]」とかでも書けそう

[実例の画像を添える]

読んだら実践してな。成果報告待ってるで。
```

### 切り口の複数提示テンプレート（定説を覆す型）
```
"[ジャンル]は難しい・売りづらい"と言われているけど、
全然そんなことない。

[ジャンル]を[ジャンル]のまま売ろうとしてるから無理なだけ。

私だったらこう売ります。

「[切り口1のキャッチコピー]」を[ターゲット界隈1]に切り込んで売るとか…
「[切り口2のキャッチコピー]」を[ターゲット界隈2]に切り込んで売るとか…
「[切り口3のキャッチコピー]」を[ターゲット界隈3]に切り込んで売るとか…

切り口を変えてみて。どこからでも集客できるよ。

[マインドマップ・画像で詳細を補足]
```

## 注意点

- **専門性と分かりやすさのバランスを取る**：専門性を強調しすぎて内容が難解にならないよう、必ず具体例・画像で補う。
- **実際に語れる根拠のある分野に限定する**：ポジション＝専門家を名乗る場合、誇張した専門性の主張は信頼を損なう。実績・経験に基づく範囲でポジションを取る。
- **健康・美容関連の切り口は効果効能の断定表現に注意する**：サウナ・美肌などの切り口を扱う際、「必ず治る」「絶対痩せる」のような断定的な効果効能の表現は、景品表示法・薬機法等に抵触するリスクがある。
- **`identity/my_offer.md`・`skills/my_position.md`・`skills/values.md`を踏まえる場合**：`skills/my_position.md`の押し出す手法にある「センターピンを捉え、本質を優先して学ぶ」という価値観は、この「専門家ポジション」の考え方と直結する。ただし`skills/values.md`の落ち着いたトーンに合わせ、「本当は教えたくなかったけど」のような煽り気味の前置きは避け、淡々と専門知識を共有する形にする。
