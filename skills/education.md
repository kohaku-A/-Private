# 売上特化ポストの教育資料（再利用可能な知識）

出典：「少ないフォロワー数でも大手級の売上を叩き出す 売上特化ポスト作成テンプレ 〜月100万円を自動化した私のポスト術〜」第3章の教材画像5枚を、今後ポストを書く際に再利用できる知識として整理したもの。

## 目的

フォロワー数が少なくても、ポスト単体で売上（商品購入・コンサル成約）に直結させられる状態を作ること。単に情報を発信するのではなく、1つ1つのポストを「売れる思考回路を読者の中に作るための装置」として設計できるようになることがゴール。

## 重要な考え方

- **ポスト＝読者の思考の切り替え装置**。ポストの役割は情報伝達ではなく、読者の思考・マインドをこちらが引き寄せたい方向に動かすこと（＝教育）。
- 教育で動かす対象は主に2軸：
  - **成功者マインド**＝商品を買う人の思考（行動する人・自己投資する人の考え方）
  - **Myポジション**＝自分が押したい手法や価値観（他の発信者との差別化ポイント）
- この2軸がブレると発信の一貫性が崩れるため、**核になるコンセプト**（どういう教育をしていく発信者なのか）を先に定めておく必要がある。
- 「きちんと設計したポスト」と「闇雲に書いたポスト」では、同じ話題を扱っても売上に大きな差が出る。差を生むのは文章力そのものより、投稿前の設計の有無。

## 読者心理

読者は投稿を読む前、無意識に「行動しない言い訳」を持っている。教材ではこれを次の3つの現状維持マインドとして提示している。

| 現状維持マインド（Before） | 結果 |
|---|---|
| 現状維持でOKかなぁ... | 商品を出しても売れない |
| そのうち行動すればいいか... | チャンスを逃す |
| 知識なんていらない！自己投資も無駄！ | 炎上リスクも高い |

これに対して、教育によって読者を動かしたい先が次の成功者マインド（After）。

| 成功者マインド（After） | 結果 |
|---|---|
| 成功するには知識が大事！先人から学ぼう！ | 初速がつきやすい |
| チャンスは待ってくれないから即行動しよう！ | 成果が出やすい |
| 自己投資して時間を削減した方がコスパいい！ | 行動が速くなる |

つまり読者心理は「今のままでいい理由」と「変わるべき理由」の綱引き状態にあり、ポストの役割はこの綱引きを後者（成功者マインド）側に少しずつ傾けていくこと。1投稿で完全に変える必要はなく、繰り返し接触することで教育が積み上がる前提で設計する。

## ポスト設計の原則

1. **書く前に3つの問いに答える**：このポストで「どんな感情にさせたいか」「どんな価値観にさせたいか」「どんな見せ方をしたいか」を先に決めてから書き始める。行き当たりばったりで書かない。
2. **Before→Afterの対比構造を使う**：読者の中にある現状維持マインドを言語化して見せた上で、成功者マインドを対比で提示すると、思考の切り替えが起きやすい。片方だけを書くより効果が高い。
3. **教育は一貫したコンセプトの上に乗せる**：Myポジション（押したい手法・価値観）から外れた内容を発信すると、読者に矛盾したメッセージを送ることになり教育が積み上がらない。
4. **売上インパクトを意識する**：このアプローチが機能すると、低単価コンテンツが自然に売れる／高単価コンサルが売り込みなしで売れる／いいねやリプの熱量が上がる／フォロワーが伸びる／企画への反応が早くなる、という結果に繋がる。ポストを書く際は「これは読者のどのマインドを動かすためのポストか」を常に意識する。

## 実際に使えるテンプレート

### Before / After 対比テンプレート
```
[現状維持マインドの内的独白を2〜3個列挙]
（例：「〇〇でOKかなぁ...」「そのうち〇〇すればいいか...」「〇〇なんていらない、〇〇も無駄！」）

→ そのままだと[デメリットを一言]

でも、[転換の一言]

[成功者マインドの主張を2〜3個、同じ数だけ対で列挙]
（例：「〇〇には〇〇が大事、先人から学ぼう」「チャンスは待ってくれないから即行動」「〇〇した方がコスパいい」）

→ だから[得られるメリットを一言]
```

### 投稿前セルフチェックテンプレート（設計メモとして使う。投稿本文には出さない）
```
このポストは...
・読者にどんな感情を抱かせたい？　→（　　）
・読者にどんな価値観を持たせたい？　→（　　）
・どんな見せ方（切り口）で見せる？　→（　　）
・このポストはMyポジションのどの主張と繋がっている？　→（　　）
```

## 注意点

- Before部分（現状維持マインドの代弁）を書きすぎたり煽りすぎたりすると、読者を不快にさせたり説教くさくなったりするリスクがある。あくまで「気づきを与える」範囲にとどめ、読者を見下すトーンにしない。
- 「月20〜40万円→月70〜100万円」のような具体的な実績数字を使う場合は、実際の実績に基づいて書くこと。誇張・虚偽の数字は信頼を損なうだけでなく、実際のビジネスで使う場合は景品表示法などの規制に抵触するリスクもあるため、事実確認をユーザー自身に必ず確認する。
- Before/After構造は強力だが、毎回同じ言い回しを使うとパターンが読者に見透かされて効果が落ちる。表現のバリエーションを持たせる。
- 教育目的の投稿ばかりだと押しつけがましくなるため、日常投稿や実績報告など他パターンと組み合わせてバランスを取る（`skills/content-seller-post-writer/references/patterns.md` の5パターンと併用できる）。

## 今後ポストを書く時に必ず守るルール

1. 書き始める前に「感情」「価値観」「見せ方」の3点を必ず決めてから書く。
2. Myポジション（自分が押したい手法・価値観）とズレる内容を発信しない。
3. 読者の現状維持マインドを想像し、それをBefore、動かしたい先をAfterとして対比で見せることを基本形にする。
4. 実績・売上などの具体的数字を使うときは、事実に基づいているかを必ず確認してから書く。
5. ポストは情報を伝えるだけで終わらせず、「読者の思考をどちらに動かすためのポストか」を常に意識して締めくくる。
