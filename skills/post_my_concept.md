# Myコンセプトを反映するポストの知識

出典：ポスト作成テンプレ教材「売上につながるポスト7つの要素」の⑤「Myコンセプトを反映する」を掘り下げた画像2枚（コンセプト解説1枚＋実例注釈3種）を、今後ポストを書く際に再利用できる知識として整理したもの。

この資料は`skills/post_principles.md`で挙げた7要素のうち5番目「Myコンセプトを反映する」の詳細版にあたる。他の要素（ポジション、エンゲージメント、導線、リアルタイム性、一文目のフック、共通言語）は`skills/post_principles.md`・`skills/post_positioning.md`・`skills/post_engagement.md`・`skills/post_cta.md`・`skills/post_realtime.md`を参照。

## 目的

**「自分の価値観を反映したポストを作る」**ことで、「めちゃくちゃ共感する！」「〇〇さんの考え方好きだなぁ」という強い共感・ファン化を生むこと。単なる情報発信ではなく、自分がどんな人生観・働き方観を持っているかを繰り返し発信することで、フォロワーとの価値観レベルでの結びつきを作るのが狙い。

## 構成

Myコンセプトの例として、次のような価値観が挙げられている。

- ストレスなく好きなテーマでやりたい！
- 縛られず自由な場所で好きな人と一緒に働きたい！
- ゴリゴリ働くより自動化して時間の余裕を作りたい！

実例では、Myコンセプトを複数の切り口で反映している。

1. **「日常＞仕事」という切り口で理想を見せる**：過去の苦労（大変だった経験）→仕組み化・自動化した内容→「その結果、最高。今日まだ犬の散歩しかしてないのに」という日常の充実を、実績（売上のスクリーンショット等）と組み合わせて見せる。
2. **「好きを仕事にできる」という価値観を出す**：自分が学んだこと・打ち込んだことがそのままコンテンツになり、お金として返ってくる、というロジックを言語化する（自己成長・他者貢献・時間やお金からの解放、という3点セットで語られている）。
3. **「お金よりも日常を重視する」「時間に縛られない」という価値観**：朝起きての売上通知より、愛犬や恋人・家族が元気に生きてることの方が幸せ、という日常への言及。「あ、今起きました」のような時間に縛られない生活の描写を添える。

## 書き方

- **価値観は具体的な生活の一コマとセットで表現する**：抽象的な理念だけでなく、「犬の散歩」「今起きました」のような具体的なシーンで示すと説得力が増す。
- **売上実績と日常の充実を組み合わせて見せる**：「その結果、最高。今日まだ犬の散歩しかしてないのに」のように、頑張っていないのに結果が出ている、という自動化・仕組み化の価値観を実績と一緒に見せる。
- **「〇〇が仕事になる」という価値観にはロジックを添える**：自分が学んだこと・打ち込んだことが全てコンテンツ化される、という構造を説明すると価値観に説得力が生まれる。
- **共感を誘う問いかけで締める**：「わかってくれる人いる？」のような一言で、読者の共感を引き出す。
- **カジュアルな言い回しで人間味を出す**：「今起きました…エヘ」のような軽さを添えると、価値観の押し付けがましさが和らぐ。

## テンプレート

### 日常＞仕事型テンプレート
```
[過去の苦労・大変だった経験]

その経験から、[仕組み化・自動化した内容]を作り上げた。

その結果、最高。
今日まだ[日常の一コマ]しかしてないのに…

[実績を示す画像・スクリーンショット]
```

### 価値観の言語化型テンプレート
```
自分が[学んだこと・打ち込んだこと]を学べば
それが[コンテンツ]に
[別の学び]に挑戦すれば
それが[別のコンテンツ]に

自分を磨くために取り組んだことが全て[資産]になって
またお金として返ってくる

・[価値観1：自己成長]
・[価値観2：他者貢献]
・[価値観3：時間やお金からの解放]

ができる[仕事・活動]。
まじで天職。愛してます。
```

### お金より日常型テンプレート
```
ぶっちゃけさ、
[仕事上の嬉しい出来事]も嬉しいけど…

毎日[日常の一コマ]と
[大切な人・存在]がみんな元気に生きてる。

それだけで[私]は
十分幸せじゃよ。

この感覚は忘れないようにしたいよね。

わかってくれる人いる？

[日常のカジュアルな一言で締める]
```

## 注意点

- **価値観の主張と実態を乖離させない**：「時間に縛られない」と言いながら常に働いているような矛盾したポストが続くと信頼を損なう。
- **実績の誇張を避ける**：売上実績と日常の充実を組み合わせる際、`skills/change_post.md`と同様、数字を誇張しない。
- **Myコンセプトは`identity/my_offer.md`・`skills/my_position.md`の価値観と一致させる**：教材の元の価値観（「ゴリゴリ働くより自動化」「日常＞仕事」等）をそのまま使うのではなく、このプロジェクト自身のMyポジション（「フォロワー数より信頼残高」「バズより教育」等）を反映する。
- **`identity/my_offer.md`・`skills/my_position.md`・`skills/values.md`を踏まえる場合**：この要素はまさに`skills/my_position.md`全体（押し出す価値観・ブランド人格）を体現するためのポスト技法にあたる。実際に書く際は、`skills/my_position.md`の「自己流で1年半遠回りしたから」「平和に仕事したい」「仕事にも売上にも支配されたくない」というブランド人格の3つの実体験をそのまま素材として使うとよい。トーンは`skills/values.md`の落ち着いた文体・絵文字ルールに従う。
