# エンゲージメントをとるポストの知識

出典：ポスト作成テンプレ教材「売上につながるポスト7つの要素」の②「エンゲージメントをとるポスト」を掘り下げた画像3枚（コンセプト解説1枚＋とりたいエンゲージメントの解説1枚＋実例注釈1枚）を、今後ポストを書く際に再利用できる知識として整理したもの。

この資料は`skills/post_principles.md`で挙げた7要素のうち2番目「エンゲージメントをとる要素をいれる」の詳細版にあたる。他の要素（ポジション、導線、リアルタイム性、Myコンセプト、一文目のフック、共通言語）は`skills/post_principles.md`および`skills/post_positioning.md`を参照。

## 目的

**「いいねやリプを促す」**ことで、エンゲージメント（反応）を能動的に獲得すること。前提として**「人間は反応を促されないと反応しない」**という原則がある。明示的に行動を促すことで反応率が上がるだけでなく、副次的な効果として次の連鎖が生まれる。

- リプの習慣がつくと、何も言わずともリプするようになる。
- リプが増えると、それを見た他の人もリプするようになる。

さらに、エンゲージメントが増えることでアルゴリズム的にも有利になる、という実務的なメリットもある。

## 構成

**とりたいエンゲージメントの種類**

- いいね
- リプに特定の言葉を送ってもらう
- リプに自分の感想を送ってもらう

**エンゲージメントを取るためのポイント**

- **行動する理由を用意してあげる**：「知りたい人はいいねで教えて」のように、反応する動機を明示する。
- **リプで送るべき言葉を用意してあげる**：「リプで🐶って送ってね！」のように、送る内容そのものを指定してハードルを下げる。

実例では、これをさらに発展させた**「DMを送らせる」漏斗（ファネル）**が使われている。構成要素は次の通り。

1. **一文目で興味づけ**：強い断定文でフックする（`skills/post_principles.md`の要素6と接続）。
2. **仮想敵批判**：世間で言われていることを否定する（`skills/problem_post.md`と接続）。
3. **理想の未来を見せる**：具体的な実績・成果を提示する（`skills/change_post.md`と接続）。
4. **恐怖訴求**：このままでは生き残れない、というプレッシャーをかける（`skills/problem_post.md`の危険性訴求と接続）。
5. **DMを送らせる**：質問を投げかけ、回答をDMで送ってもらう。「先着n名までにはお答えします」という限定性を組み合わせる。
6. **画像で欲求を刺激**：実際の成果物（売上通知等）のスクリーンショットを並べて視覚的に見せる。

## 書き方

- **反応する具体的な理由・条件を用意する**：「〇〇な人はいいねで教えて」のように、なぜ反応すべきかを明示する。理由がないと人は反応しない。
- **リプで送ってほしい言葉を明示的に指定する**：絵文字や合言葉など、送るハードルを最小化した具体的な指示にする。
- **同じ形式のCTAを継続して使う**：単発ではなく繰り返し使うことで、フォロワーが「毎回リプする人」になっていく（リプの習慣化）。
- **より高度なエンゲージメント（DM）は質問形式＋限定性で強化する**：「先着n名に回答する」という限定性を組み合わせると、DMを送る動機が強まる。
- **前後に他の要素を組み合わせて反応する動機自体を強化する**：仮想敵批判・理想の未来・恐怖訴求などを組み合わせることで、単なるCTAより反応が引き出しやすくなる。
- **画像を添えて視覚的に欲求を刺激する**：成果物のスクリーンショット等をテキストに添えると、行動喚起力が上がる。

## テンプレート

### 基本テンプレート（シンプルなCTA型）
```
[本題の投稿内容]

知りたい人は"いいね"で教えて！

[またはリプ喚起]
「[合言葉／感想]」ってリプで送ってね！
```

### DM誘導ファネル型テンプレート
```
[一文目で興味を引く強い断定文]

[仮想敵批判：世間で言われていることを否定する]

[理想の未来：具体的な実績・成果を見せる]

[恐怖訴求：このままだと生き残れない、というプレッシャー]

さて。
[質問文：〇〇について私が意識してることって何だと思う？]

DMで自分なりの回答送ってくれた人、
先着[人数]名までにはお答えします。

[画像で欲求を刺激（成果物のスクリーンショット等）]
```

## 注意点

- **CTAを毎回入れすぎない**：エンゲージメント目的のCTAを詰め込みすぎると、投稿の販促色・作為性が強くなりすぎる。`skills/post_principles.md`の注意点にもある通り、7要素を毎回全部盛り込む必要はない。
- **DM誘導ファネルは複数の注意点が重なる技法**：恐怖訴求・仮想敵批判・希少性（先着n名）を組み合わせるため、`skills/problem_post.md`・`skills/action_post.md`双方の注意点（煽りすぎない、偽の希少性を作らない、個人攻撃にしない）がすべて適用される。
- **画像に個人情報が映り込まないよう配慮する**：口座情報・氏名等が見える場合は加工する（`skills/recommended_method_post.md`・`skills/reproducibility_post.md`と同様）。
- **`identity/my_offer.md`・`skills/my_position.md`・`skills/values.md`を踏まえる場合**：`skills/my_position.md`は「短期の刈り取り型ビジネスはやりたくない」「本当に必要な人にしか売りたくない」という価値観を掲げている。「先着3名」のような限定性を使う場合は、実際に対応可能な人数の範囲で使い、煽りのための偽の限定にしない。また`skills/values.md`の落ち着いたトーンからは、「もうそろそろ死にそう」のような強い断定的な恐怖訴求は避け、事実に基づいた穏やかな注意喚起にとどめる方が、このプロジェクトの声には合う。
