# 推奨手段を伝えるポストの知識

出典：ポスト作成テンプレ教材「Type03：推奨手段を伝えるポスト」の画像5枚（コンセプト解説1枚＋構成解説1枚＋比較構造図1枚＋仕組み説明の解説1枚＋優位性の解説1枚）を、今後ポストを書く際に再利用できる知識として整理したもの。

## 目的

読者の悩み・欲求の達成に向けて「おすすめの手段」を伝えること。伝えるだけでなく、同時に他の手段を選択肢から削ることで、読者の中に「〇〇さんの商品いいな！」という一択の思考を作る。自分の手段や商品が良いというロジックを組み立て、比較対象になりうる別の手段・別の商品を選択肢から排除するのがゴール。

## 構成

推奨手段の説得力は、**2段階の比較構造**で組み立てる。

1. **手段レベルの比較**：自分が推している手段（例：X運用）と、別の手段（例：インスタ運用／YouTube／せどり）を比較し、別の手段を選択肢から排除する。
2. **商品レベルの比較**：手段が絞れた上で、自分の商品・手法（例：ぽにょ式X運用）と、同じ手段の中の別の商品・手法（例：別のX運用ノウハウ）を比較し、別の商品を選択肢から排除する。

「手段では自分の陣地（X運用というカテゴリ）に読者を引き込み、商品ではその陣地の中で自分だけを選ばせる」という二段構えになっている点が重要。手段の話と商品の話を混同すると論理が弱くなる。

各レベルの比較は、次の5つの問いに答える形で構成する。

- どんな仕組みでうまくいくのか？
- 他と比べてなぜその手法が優れているのか？
- 他と比べてなぜその商品が優れているのか？
- なぜ別の手段ではいけないのか？
- なぜ別の商品ではいけないのか？

さらにこの5つは大きく2種類の理由付けに整理できる。

- **仕組みの説明**：その手法がどんな仕組みで理想の未来を実現するのか、なぜその手法がうまくいくのかを語る（メカニズムの説明）。
- **優位性の説明**：他と比べて何が優れているのかを語る（比較優位の説明）。

## 書き方

- **手段→商品の順で語る**：先に「なぜこのカテゴリ（手段）を選ぶべきか」を語り、その後に「その中でもなぜ自分の商品・手法を選ぶべきか」を語る。順番を守ると、読者の思考が段階的に絞り込まれていく。
- **仕組みの説明は「メリットの理由」とセットで書く**：仕組みそのものを説明するだけでなく、それが読者にとって具体的にどう有利かを添える（例：「非稼ぐ系ならライバルが少ない」「リサーチすれば売れ筋商品がわかる」「初心者でも良い商品が作れれば口コミで広がる」）。
- **優位性は複数のフレーズから選んで組み合わせる**：「成果が出る期間が短い」「かんたんで労力が少ない」「コスパがいい」「初期の労力が少ない」「大きな成果が狙える」「長期的にメリットが大きい」「初心者でも成果が出る」「センスが必要ない」「再現性高い」など。全部詰め込むと薄まるので、テーマに合わせて3〜4個に絞る。
- **「別の手段/商品ではいけない理由」は間接的に語る**：別の選択肢を直接否定・批判するのではなく、自分側の優位性を語ることで相対的に他を排除する方が角が立ちにくい。直接的な批判をしたい場合は`skills/problem_post.md`の仮想敵批判の型と組み合わせる。
- **比較の軸を揃える**：手段の比較では「カテゴリ同士」（X運用 vs インスタ運用）、商品の比較では「同カテゴリ内の具体的な手法同士」（自分のX運用ノウハウ vs 他の人のX運用ノウハウ）というように、比較する粒度を揃える。異なる粒度を混ぜると論理が破綻する。

## テンプレート

### 基本テンプレート（手段→商品の2段階排除）
```
[読者の悩み・欲求]を叶える方法は色々あるけど、

私は[推奨する手段]をおすすめしてる。

なぜなら[手段の仕組み・メリットの理由を1〜2個]

「[別の手段の例1]」「[別の手段の例2]」「[別の手段の例3]」じゃダメなの？って思うかもだけど、
[推奨する手段の比較優位性を1〜2個（成果が出る期間・労力・再現性 等から選ぶ）]

じゃあ[推奨する手段]の中なら何でもいいかというと、そうでもなくて。

[自分の商品・手法]は[商品レベルでの仕組みの説明]

[自分の商品ならではの比較優位性を1〜2個]

[CTA・導線]
```

### 仕組み説明特化テンプレート（「どんな仕組みでうまくいくのか」を掘り下げる版）
```
[推奨手段]がなぜうまくいくのか、仕組みを説明すると

・[仕組み上のメリット1]（例：ライバルが少ない）
・[仕組み上のメリット2]（例：リサーチすれば売れ筋がわかる）
・[仕組み上のメリット3]（例：初心者でも口コミで広がる）

だから、[理想の未来]を実現できる。
```

## 注意点

- **別の手段・商品を名指しで否定しない**：比較優位を語る際、特定の競合商品・発信者・サービス名を出して直接的に貶さない。カテゴリレベルの言及にとどめ、個人攻撃・誹謗中傷・営業妨害と受け取られる表現を避ける。
- **優位性の主張は事実に基づくこと**：「コスパがいい」「センスが必要ない」「再現性高い」といった主張を誇張すると、誇大広告的になり信頼を損なう。実際にそう言える根拠がある場合のみ使う。
- **手段レベルと商品レベルの比較を混同しない**：「Xがいい理由」の中に「自分の商品がいい理由」を混ぜて語ると、読者にとって論理が追いにくくなる。段階を分けて書く。
- **他資料との組み合わせ方**：
  - `skills/problem_post.md`の「問題点を指摘するポスト」で読者の思考に余白を作った直後に、この資料の「推奨手段の提示」で自分の手段・商品に誘導する、という連続した使い方が典型的。
  - `skills/change_post.md`の理想の未来描写（After）は、この資料の「仕組みの説明」の中で理想の未来を語る部分と接続できる。
  - `skills/education.md`の「成功者マインド／Myポジション」の教育構造とも接続しており、この資料の比較ロジックはMyポジション（押したい手法）を確立するための具体的な武器として使える。
