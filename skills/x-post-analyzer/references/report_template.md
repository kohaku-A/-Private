# Xポスト分析レポート テンプレート

特に指示がない限り、このテンプレートの構成でレポートを作成する。投稿件数や利用可能な指標に応じて、該当しないセクションは「データなし」と明記した上で簡略化してよい。

```markdown
# Xポスト分析レポート

## 対象データ
- 分析対象の投稿数
- 期間（分かる場合）
- 利用できた指標（いいね/リポスト/返信/インプレッションのうち何が揃っていたか）

## サマリー
分析全体から言える最も重要なポイントを2〜3行で。

## 傾向分析
投稿群に共通する話題のジャンル・文体・構成パターン。

## 感情分析
投稿ごと（または全体）のトーン傾向と、トーンとエンゲージメントの関係。

## トピック抽出
頻出トピック・キーワードの一覧とクラスタリング。

## エンゲージメント傾向分析
- エンゲージメント率の全体傾向（平均・中央値、算出できなければ絶対数で代替）
- 特に伸びた投稿・沈んだ投稿とその特徴
- 内容要素（長さ、メディア有無、時間帯、CTAの有無など）とエンゲージメントの関係

## 改善提案
次の投稿に活かせる具体的なアクション（3〜5個）。それぞれ根拠となったデータ上の傾向を一言添える。
```
