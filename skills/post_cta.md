# 導線に流すポストの知識

出典：ポスト作成テンプレ教材「売上につながるポスト7つの要素」の③「導線に流すポスト」を掘り下げた画像2枚（コンセプト解説1枚＋実例注釈2種）を、今後ポストを書く際に再利用できる知識として整理したもの。

この資料は`skills/post_principles.md`で挙げた7要素のうち3番目「導線に流す要素をいれる」の詳細版にあたる。他の要素（ポジション、エンゲージメント、リアルタイム性、Myコンセプト、一文目のフック、共通言語）は`skills/post_principles.md`・`skills/post_positioning.md`・`skills/post_engagement.md`を参照。

## 目的

**「固定ポストに読者を流す」**ことで、ポストを読んだだけで離脱してしまう読者を、資産となる固定ポスト（詳細情報・商品への入り口）へ誘導すること。前提として、**ポストからわざわざプロフィールに飛んでくれる人はごく一部**であり、固定ポストへの導線を定期的に露出しないと「売り逃し」が発生する。**そもそもポストは導線に人を集めるための手段でしかない**ため、積極的に固定ポストへ誘導することが重要になる。

## 構成

実例を分解すると、導線に流すポストには次の2パターンがある。

**パターン1：問題点の指摘→固定ポスト誘導**
1. 問題点を一言で指摘する（`skills/problem_post.md`と接続）。
2. その解決策が固定ポストにあることを示す。
3. 軽いトーンで誘導する（「ここが1番おもろいんだから、早くこっちおいでよ」）。

**パターン2：問題点の指摘→解決策の提示→限定リンク誘導**
1. 読者が抱えていそうな複数の問題点を列挙する。
2. 問題の原因を一言で言い切る（「単に事例不足なだけ」）。
3. 解決策を具体的なチェックリストで示す。
4. 「集め方がわからないなら」と繋げ、無料記事・固定ポストへのリンクを矢印（↓↓↓／↑↑↑）で挟んで見せる。
5. 「近々この記事は奥にしまう」のような限定性を添える。
6. 広告リンクの場合は`#ad`を明示する。
7. 締めの一文で背中を押す（「"できない"なら"できる"ようになるまで学べばいい。それだけ。」）。

## 書き方

- **固定ポストへの誘導は繰り返し入れる**：1回だけでなく、複数の投稿で継続的に露出させる。露出を止めると売り逃しが生まれる。
- **誘導前に問題提起をセットにする**：`skills/problem_post.md`の型（問題点の指摘→原因→解決策）を使い、その解決策の在り処として固定ポストを提示すると、誘導の説得力が増す。
- **限定性を添えて行動を後押しする**：「気が変わらないうちに」「近々奥にしまう」のような一言を添える（`skills/action_post.md`の機会損失フレーミングと接続）。
- **リンクは矢印で視覚的に誘導先を明確にする**：「↓↓↓」「↑↑↑」のように、リンクの位置をテキストで示すと迷わせない。
- **広告・アフィリエイトリンクには広告表記を入れる**：`#ad`等の表記を必ず添える（`skills/problem_post.md`の注意点と同じ）。

## テンプレート

### 基本テンプレート（問題提起→固定ポスト誘導）
```
[問題点を一言で指摘]

[問題の背景説明]

[テーマ]のやり方は固定ポストで解説してるからね。
もう何人も自分の[成果]で[結果]してるよ。

[限定性を添える一言]（例：気が変わらないうちに早く記事読んどいてね）
```

### 解決策提示＋限定リンク誘導型テンプレート
```
「[問題点の内的独白1]」
「[問題点の内的独白2]」
「[問題点の内的独白3]」

これらの「できない・わからない」系の問題って、
単に"事例不足"だと思うんだよね。

[問題点]のであれば、
・[チェックリスト項目1]
・[チェックリスト項目2]
・[チェックリスト項目3]
をみたらいい。

集め方がわからないなら、
[テーマ]の事例の集め方について無料で記事を書きました。
↓↓↓
[リンク]
↑↑↑

近々この記事は奥にしまうので、
ここで無料で見れるのは今だけです

#ad

"できない"なら"できる"ようになるまで学べばいい。それだけ。
学び方は↑↑↑に置いておきましたからね。
乗り遅れないようにね。
```

## 注意点

- **誘導を毎回入れすぎない**：導線への誘導が続きすぎると宣伝色が強くなる。`skills/post_principles.md`の7要素は全部を毎回盛り込む必要はないという注意点がここでも当てはまる。
- **限定性は事実に基づいて使う**：「今だけ」「近々しまう」を、実際には変わらない内容に対して使うと、`skills/action_post.md`・`skills/my_position.md`が指摘する「偽の希少性」の問題に該当する。
- **広告リンクには必ず表記を入れる**：`#ad`等の表記なしで商用リンクへ誘導しない。
- **`identity/my_offer.md`・`skills/my_position.md`・`skills/values.md`を踏まえる場合**：`skills/my_position.md`の押し出す手法「X内で集客→教育まで完結し、するりと売れる導線設計」「リストを取得して資産化する発信」と、この技法は直結する。固定ポストへの誘導は単発の売り込みではなく「教育の入り口」として機能させると価値観と整合する。誘導の文言は`skills/values.md`のトーン（落ち着いた、テンション芸を避ける）に合わせ、「気が変わらないうちに」のような煽り文句は避け、淡々と「詳しくは固定にまとめてます」程度にとどめる方がこのプロジェクトの声に合う。
