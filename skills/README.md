# skills/ 索引

このフォルダは「こはく」のXポスト作成に関する知識ベース。ポスト・商品・プロフィール・note・LP・セールス文章など、あらゆる発信を書く際は、**必ず下記の順序で参照する**。

## 参照順序

1. **土台（アイデンティティ）** — 常に最優先で参照する
2. **投稿タイプ別技法（Type01〜07）** — 「何を書くか（切り口）」を1つ選ぶ
3. **横断原則（7要素）** — 選んだ切り口を「どう仕上げるか」を2〜3個意識して肉付けする

土台の内容と、Type別技法・7要素の内容が矛盾する場合は、**必ず土台を優先する**。Type別技法・7要素は別アカウントの分析から作られたテンプレート集であり、土台（アイデンティティ）の価値観・声のトーンでフィルタしてから使う。

---

## 1. 土台（アイデンティティ）

| ファイル | 役割 |
|---|---|
| `identity/my_offer.md` | 誰に、何を届けるか（対象読者・提供する変化・なぜ届けたいか） |
| `skills/my_position.md` | 何を支持し、何を拒むか（押し出す／否定する価値観・手法、ポジショントーク） |
| `skills/values.md` | どんな声・トーンで話すか（キャラクター・文体・絵文字ルール） |

## 2. 投稿タイプ別技法（Type01〜07）

売上特化ポスト作成テンプレ教材の各投稿タイプ。1投稿につき基本1つの型を選ぶ。

| ファイル | Type | 概要 |
|---|---|---|
| `skills/change_post.md` | 01 | 変化を見せる（Before/After型）。どん底→理想の未来の対比で憧れを起こす |
| `skills/problem_post.md` | 02 | 問題点を指摘する。原因の指摘／仮想敵批判／危険性訴求で思考の余白を作る |
| `skills/recommended_method_post.md` | 03 | 推奨手段を伝える。手段→商品の2段階比較で選択肢を絞り込む |
| `skills/reproducibility_post.md` | 04 | 再現性を伝える。「自分にもできそう」という最後の壁を崩す |
| `skills/empathy_post.md` | 05 | 共感を得る。過去を語る／発信理念／向上心でファン化する |
| `skills/action_post.md` | 06 | 行動の重要性を説く。先延ばし心理を崩し即行動を促す |
| `skills/self_investment_post.md` | 07 | 自己投資の重要性を説く。損失回避を軸に自己投資マインドへ転換する |
| `skills/education.md` | — | 上記に通底する教育構造（現状維持マインド→成功者マインドの切り替え） |

## 3. 横断原則（売上につながるポスト7要素）

Type01〜07のどれで書く場合でも、差別化のために肉付けする7要素。全部盛り込む必要はなく、2〜3個を意識する。

| ファイル | 要素 | 概要 |
|---|---|---|
| `skills/post_principles.md` | 総論 | 7要素の全体像、Type01〜07との位置づけ、実践のコツ |
| `skills/post_positioning.md` | ① | ポジションをとる。専門家としてのニッチを明示する |
| `skills/post_engagement.md` | ② | エンゲージメントをとる。いいね・リプを促すCTA設計 |
| `skills/post_action_trigger.md` | ②補足 | 行動トリガー。読者が反応する5つの心理的理由 |
| `skills/post_cta.md` | ③ | 導線に流す。固定ポストへの誘導設計 |
| `skills/post_realtime.md` | ④ | リアルタイム性を出す。「動いてる感」の作り方 |
| `skills/post_my_concept.md` | ⑤ | Myコンセプトを反映する。自分の価値観を反映させる |
| `skills/post_hook.md` | ⑥ | 一文目で惹きつける。冒頭フックの8技法 |
| `skills/post_common_language.md` | ⑦ | 共通言語を作る。独自の語彙・絵文字でマインドシェアを取る |

## 4. その他のスキル

## 実際にポストを書くときの流れ

1. `identity/my_offer.md`・`skills/my_position.md`で、今回のお題が誰に何を届けるものか確認する。
2. Type01〜07から、お題に合う切り口を1つ選ぶ（複数組み合わせてもよい）。
3. `skills/post_principles.md`のチェックリストを見ながら、7要素のうち2〜3個を意識して肉付けする。
4. `skills/values.md`の文体・絵文字ルールで最終的な表現を整える（他ファイル由来の関西弁・煽り表現・🥺等はここで置き換える）。
