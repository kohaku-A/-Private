# リアルタイム性を出すポストの知識

出典：ポスト作成テンプレ教材「売上につながるポスト7つの要素」の④「リアルタイム性を出すポスト」を掘り下げた画像2枚（コンセプト解説1枚＋実例注釈2種）を、今後ポストを書く際に再利用できる知識として整理したもの。

この資料は`skills/post_principles.md`で挙げた7要素のうち4番目「ポストにリアルタイム性をだす」の詳細版にあたる。他の要素（ポジション、エンゲージメント、導線、Myコンセプト、一文目のフック、共通言語）は`skills/post_principles.md`・`skills/post_positioning.md`・`skills/post_engagement.md`・`skills/post_cta.md`を参照。

## 目的

**「中の人が新しいことに挑戦してる、動いてる感」**を出すこと。Botのようにいつも同じようなポストばかりだと、読者のマインドシェアを奪えない。**「今日はこの人何してるのかな？」「この人、最近動いてるから気になるな」**という状態を読者の中に作り出すことで、継続的な関心・注目を維持することが目的。

## 構成

核心メッセージ：**今挑戦してることやしてることの発信も大事**——Botのような静的な発信ではなく、「今まさに動いている」ことを見せる。

実例には2つのパターンがある。

1. **「今準備してます！」というリアルタイム感**：読者の反応を受けて即座に動いている様子を見せる（例：「昨日のポストにたくさん反応いただいたので、早速準備してます！」）。具体的な配布日時を予告し、フォロー＆通知オンを促す形で締める。
2. **「動いてるリアルタイム感」を行動そのもので見せる**：実際に取り組んでいる活動（潜入調査等）をその場から実況し、その活動の目的・理念（読者理解のためにどこまでもやる、という発信理念）を添えて説得力を持たせる。

## 書き方

- **反応を受けての即時対応を見せる**：「たくさん反応いただいたので早速準備してます」のように、読者の行動に対してすぐ動く様子を発信する。
- **具体的な日時を予告する**：「明日10/20の19:00くらいから」のように次の展開の時間を明示すると、フォロー・通知オンへの行動喚起にも繋がる（`skills/post_action_trigger.md`と接続）。
- **進行中の活動をそのまま実況する**：「〇〇に潜入調査に来ております」のように、今まさに行っていることを一人称で実況する。
- **活動の理由・理念を添える**：単なる行動報告で終わらせず、「なぜそれをしているのか」（読者理解のため等）を添えると、`skills/empathy_post.md`の発信理念を語る技法と重なり、説得力が増す。
- **画像・スクリーンショットで臨場感を補強する**：実際に使っているアプリの画面等を添えると、実況の信憑性が増す。

## テンプレート

### 即時対応型テンプレート
```
昨日（さっき）のポストに
たくさん反応いただいたので、
早速準備してます！

[準備している内容の説明]

[配布・公開予定の日時]から
[入手方法]するので、
フォロー＆通知オンにして待機しといてください
```

### 実況型テンプレート
```
[目的]を[達成する]べく、
[具体的な活動・場所]に来ております。
（[活動の分野・文脈]）

わたしは[理念・信念]のためなら
「[具体例1]」だって「[具体例2]」だって[行動]します。

だって結局
[専門分野]で大事なのって

・[理由1]
・[理由2]

この[数]つに尽きるから。

だから[理念]のためなら何も惜しまない。

[実際の活動の画像・スクリーンショットを添える]
```

## 注意点

- **実際に行っていない活動を「今やっている」と偽らない**：誠実性の観点で最も重要な注意点。リアルタイム感の演出は事実に基づく。
- **予告した日時は実際にその通り実行する**：配布日時等を予告した場合、実行しないと信頼を損なう（`skills/action_post.md`の偽の希少性回避と同じ理由）。
- **実況する活動を本題（専門分野）と結びつける**：`skills/post_principles.md`のMyコンセプト反映の要素と接続させ、活動と発信の一貫性を保つ。
- **`identity/my_offer.md`・`skills/my_position.md`・`skills/values.md`を踏まえる場合**：`skills/empathy_post.md`の「向上心を見せる」技法（先生ポジションよりリーダーポジション、文脈切れの防止）と、このリアルタイム性は直結する概念であり、組み合わせて使うとよい。`skills/values.md`のトーンでは、「動いてる感」を演出する際もテンション高く騒ぐのではなく、淡々と「今〇〇してる」という事実ベースの実況にとどめる方がこのプロジェクトの声に合う。
