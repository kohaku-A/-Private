# 投稿パターン集

x-post-analyzerによる45投稿の分析（`analysis_source.md`参照）で見つかった5つの構成パターンと、それぞれのテンプレート・実例からの抜粋。実例は `posts/post-01.md`〜`post-45.md`（リポジトリ直下）の実データを要約したもの。

## 1. 逆境ストーリー系

**構成**：①辛かった過去の具体的描写 → ②転換点（気づき・行動） → ③今の充実との対比 → ④共感を誘う問いかけ

**テンプレート**：
```
[過去の具体的な数字・状況]（給料・労働時間・年数など）

[その辛さを描写する1〜2文。涙・不安などの感情語を入れる]

そんな私が、[転換点となった行動]をして今は[今の状態]。

[過去の自分と今の自分を対比する一言]

同じように思ってた（思ってる）人おる？🥺
```

**実例からの抜粋**（`posts/post-01.md`, `post-30.md`, `post-41.md` より要約）：
- 「ウチの会社は副業禁止です」への反発から起業し3年目、というオープニング
- 「動物看護師として7時〜23時まで働き…2時までブログ書いて次の日6時に起きる」という過酷な生活描写
- 「偏差値38、最終学歴専門卒」という自己開示から始まる実績報告

**ポイント**：具体的な数字（給料15万円、勤務14時間、偏差値38など）を入れると生々しさが増す。感情語（涙、しんどい、不安）は1投稿に1〜2回に絞り、過剰にならないようにする。

## 2. 実績・売上報告系

**構成**：①見出し的な実績数字を最初に提示 → ②その数字の内訳・背景 → ③次の目標や謙遜（まだ足りない、という煽り） → ④次の展開への予告

**テンプレート**：
```
【ご報告】[期間]で[実績の数字]達成🥺

でも、[さらに大きな目標]を考えるとこのスピード、[謙遜・煽りの一言]

[次にやること・出すものの予告]

期待して待ってて🥺
```

**実例からの抜粋**（`posts/post-06.md`, `post-41.md`, `post-44.md` より要約）：
- 「今年もすでに、売上3,000万円突破」→「年収1億の目標にはまだ遅い」という自己ハードルの上げ方
- 「32万円」を見出しにして経歴（動物看護師時代）を絡めて語る構成
- 「新商品の販売なしで最高月収更新」という"らしさ"を出す切り口（頑張らずに稼げている、という余裕の演出）

**ポイント**：数字は必ず文頭か見出しに置く。金額の内訳（どの商品・どの企画由来か）を書くと信憑性が増す。「まだ足りない」という謙遜で驕り高ぶりを中和しつつ、次の展開への期待を煽って締める。

## 3. ノウハウ・Tips系

**構成**：①「〇〇は難しい/売れない」という世間の思い込みを提示 → ②それを覆す具体的な切り口・視点 → ③応用例を複数列挙 → ④「使ってみて」という軽い後押し

**テンプレート**：
```
"[ジャンル]"って[ネガティブな評判・思い込み]と言われてるけど、いとも簡単に[目的]する方法

[思い込みへの反論を一言]

私だったらこう[やる]

「[具体的な切り口1]」を[ターゲット層1]に切り込んで売るとか...
「[具体的な切り口2]」を[ターゲット層2]に切り込んで売るとか...

[ジャンル]を[ジャンル]のまま売ろうとするんじゃないの
切り口変えてみて

ぜひ使えるところは使ってくだぱい
```

**実例からの抜粋**（`posts/post-13.md`, `post-15.md` より要約）：
- 「売りづらいと言われているサウナコンテンツ」を、HSP界隈・肩こり界隈・アラフォー界隈など複数のペルソナに切り口を変えて売る提案
- 12月〜1月のイベントシーズンに合わせて恋愛系・ダイエット系・美肌系のジャンルごとに投稿テンプレートを提示

**ポイント**：具体例を3つ前後、同じ構文の繰り返しで列挙するとリズムが出て読みやすい。最後は「ぜひ使って」という軽いトーンで締め、押し付けがましくしない。

## 4. セールス・告知系

**構成**：①期待感を煽る前置き（誰にも教えたくなかった、ガチのやつ 等） → ②具体的な配布条件・日時 → ③行動しないと損する、というフレーミング → ④明確な日時・条件の再提示

**テンプレート**：
```
ほんまはまだ使いたくなかったけど…

[配布する情報・商品]、ブチ込む時が来たかもしれん...。🥹

もう、誰にも教えたくないやつ。[効果を一言で]

[配布条件（先着n名／期間限定／〇〇したら公開 など）]

期待して待ってて🥺
```

**実例からの抜粋**（`posts/post-06.md`, `post-38.md`, `post-39.md` より要約）：
- 「半年前から仕込んでたあの起爆剤」という期待感の煽り
- 「引用で考察が20件超えたら解説します」という条件付き公開の仕掛け
- 「明日（20日）19:00〜配布します」という具体的日時の明示

**ポイント**：抽象的な期待煽り（「誰にも教えたくない」）と、具体的な条件（日時・人数）をセットで書くと信憑性と緊張感が両立する。条件を曖昧にしない。

## 5. 日常・マインド系

**構成（日常寄り）**：①何気ない日常の一コマ → ②そこから得た気づき・幸福感 → ③共感の問いかけ

**構成（マインド寄り）**：①現状に対する警鐘・煽り → ②自分の行動・投資の描写 → ③読者への鼓舞

**テンプレート（日常）**：
```
[日常の一コマを短く描写]

それだけで[私／わし]は
十分幸せじゃよ。

この感覚は忘れないようにしたいよね。

わかってくれる人いる？
```

**テンプレート（マインド）**：
```
[現状維持・思い込みへの警鐘を一文で]

最近は[脅威となる他者の動き]が多すぎる...笑

[自分がとっている行動・投資]

[読者への鼓舞の一言]
```

**実例からの抜粋**（`posts/post-07.md`, `post-16.md` より要約）：
- 「愛犬が元気に尻尾振って生きてて…それだけで十分幸せ」という小さな幸福の描写
- 「現状維持で満足している人は周りにどんどん置いてかれる」から始まる自己投資エピソード

**ポイント**：日常系は絵文字を使いすぎず、素朴なトーンで短めに。マインド系は「〇〇な人が増えすぎている」という危機感を煽ってから自分の行動に繋げると説得力が出る。

## CTAライブラリ

投稿の締めに使うコールトゥアクションの型。基本は1投稿につき1つに絞る。

| CTA種別 | 使う場面 | 例文の型 |
|---|---|---|
| いいね | 共感・鼓舞系の締め | 「〇〇って人は"いいね"ください！」 |
| DM | 個別回答・限定オファー系 | 「DMで回答送ってくれた人、先着n名までにはお答えします」 |
| 引用RT | 拡散を狙いたい考察系 | 「引用で考察が◯件超えたら解説します」 |
| フォロー | 新規流入を狙う自己紹介系 | 「フォローまだの方は"フォロー"ボタンポチッとな」 |
| 固定ポスト誘導 | ノウハウ・商品訴求系 | 「いますぐ私の固定ポストから商品の作り方を学んでください」 |
| 疑問形の引き | 続きへの期待を煽りたいとき | 「さて、〇〇とは？」（回答は次の投稿に持ち越す） |
