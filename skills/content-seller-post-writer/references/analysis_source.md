# 分析の出典

このスキルの文体・構成パターンは、`posts/post-01.md`〜`posts/post-45.md`（リポジトリ直下）に保存された、あるコンテンツ販売系アカウントのXポスト45件をx-post-analyzerの手法で分析した結果に基づく。

## 分析結果サマリー

- **ペルソナ**：元動物看護師（激務・薄給）から脱サラし、コンテンツ販売（講座・教材・コンサル販売）で起業した個人アカウント。関西弁混じりの一人称口調。
- **投稿パターン（5分類）**：
  1. 逆境ストーリー系（約10件）— 過去の辛さから今の成功への転換を描く
  2. 実績・売上報告系（約10件）— 具体的な金額を見出しに、内訳と次の目標を語る
  3. ノウハウ・Tips系（約8件）— 世間の思い込みを覆す切り口を複数例示
  4. セールス・告知系（約8件）— 期待煽り＋具体的な配布条件
  5. 日常・マインド系（約9件）— 愛犬・恋人などの日常、または現状維持への警鐘
- **文体の特徴**：語尾の崩し（「〜やねん」「〜どすえ」等）、絵文字🥺🥹😉💓の要所使用、「・」を挟む強調（「だ・か・ら。」）、「――――――――」で囲むQ&Aブロック、短い段落の積み重ね。
- **CTAの特徴**：いいね・DM・引用RT・フォロー・固定ポスト誘導のいずれか1つに絞って締めることが多い。疑問形で次回への引きを作る投稿もある。
- **注意点**：投稿間で累計売上の数字に食い違いが見られた（例：「累計1.5億円」と「Xを始めて2年で累計900万円」）。実運用でこのペルソナの文体を使う場合、数字の一貫性はユーザー自身の実績に基づいて都度確認すること。

詳細な分析プロセス（傾向分析・感情分析・トピック抽出・エンゲージメント傾向分析）は、このスキルの姉妹スキルである `skills/x-post-analyzer/` を参照。パターンごとの構成テンプレートと実例抜粋は `patterns.md` を参照。
