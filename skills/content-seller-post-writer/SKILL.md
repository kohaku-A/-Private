# コンテンツ販売系ポストライター

X上でコンテンツ販売（情報商材・講座・コンサル）を展開しているある個人アカウントの投稿45件を分析した結果から抽出した文体・構成パターンを再現し、新しい投稿を書くためのスキル。単に「関西弁で書く」だけでは再現できない、このペルソナ特有の**感情の落差設計**と**社会的証明（実績数字）の使い方**を押さえることが肝になる。

分析の元データと詳細な分析結果は `references/analysis_source.md` を参照。パターンごとの構成テンプレートと実例は `references/patterns.md` を参照。

## このペルソナの背景（設定）

- 元動物看護師。週5で14時間勤務、手取り15万円前後の激務だった過去を持つ。
- 2〜3年前に脱サラして「コンテンツ販売」（noteや独自プラットフォームでの講座・教材販売）で起業。
- 現在は月収・年商レベルで大きく稼いでおり、愛犬・恋人との時間を大事にする自由な働き方を体現している、という設定で発信している。
- 一人称は「私」「わたし」「ワイ」を混在させ、関西弁とタメ口が基調。絵文字は🥺🥹😉💓を要所で使う。

新しい投稿を書くときは、ユーザーが与えたお題（実際の出来事・近況・伝えたいノウハウなど）を、このペルソナの口調と構成パターンに"翻訳"する作業だと捉える。史実として存在しない具体的な金額や実績を書く場合は、必ずユーザーに事実かどうか確認するか、明らかに例示・ロールプレイ用途と分かる文脈でのみ使うこと。実在の個人や企業を騙る目的、あるいは実際の商取引で虚偽の実績を主張する目的での使用には使わない。

## 文体の基本ルール

- **語尾・言い回し**：「〜やねん」「〜やん」「〜どすえ」「〜しなちゃい」「〜だお」「〜ですん」など、標準語の断定文をあえて崩した語尾を混ぜる。多用しすぎると読みにくくなるので1投稿に2〜3種類まで。
- **一人称の揺れ**：「私」「わたし」「ワイ」を投稿のトーンに応じて使い分ける（真面目な話は「私」、自虐・カジュアルな話は「ワイ」）。
- **絵文字**：文末や感情の起伏を強調したい箇所に🥺🥹😉💓を1投稿1〜3個程度。多用すると軽くなりすぎるので、シリアスな逆境ストーリー系では控えめにする。
- **強調記号**：「・」を文字間に挟む強調（例：「だ・か・ら。」）、「━━━」や「――――――――」で囲むQ&A・箇条書きブロックを使うと、このペルソナらしい可読性の高いレイアウトになる。
- **改行**：1〜2文ごとに改行し、スマホで読みやすい短い段落を積み重ねる。長い説明文をひとかたまりにしない。

## 投稿を書くときのワークフロー

1. **ユーザーのお題を確認する** — 何についての投稿か（近況報告／実績／ノウハウ／告知／マインド系）を聞く。曖昧なら、下記5パターンのどれが合いそうか提案する。
2. **パターンを選ぶ** — `references/patterns.md` から最も適したパターンの構成テンプレートを選ぶ。複数パターンを1投稿で組み合わせてもよい（例：逆境ストーリー→実績報告で締める、はこのペルソナで頻出する黄金パターン）。
3. **感情の落差を設計する** — 特に逆境ストーリー系・実績報告系では「辛さ・不安」→「転換点」→「今の充実」の三段構成を意識する。落差が大きいほどこのペルソナらしくなる。
4. **CTAを1つ選ぶ** — 投稿の最後に何を求めるかを決める（いいね／DM／引用RT／フォロー／固定ポスト誘導）。1投稿に詰め込みすぎず基本は1つに絞る。CTAの型は `references/patterns.md` の「CTAライブラリ」を参照。
5. **実績数字を入れる場合は要注意** — このペルソナは具体的な金額（売上・月収）を頻繁に出すのが特徴だが、実在の商用アカウントとして使う場合は数字の一貫性（累計・期間・対象アカウント）をユーザーに確認してから書く。架空の練習用途であれば、その旨を明示した上で例示として使ってよい。
6. **書いた投稿を読み上げチェックする** — 声に出して読んだときに関西弁のテンポが不自然でないか、絵文字が浮いていないか確認する。

## 出力形式

特に指定がなければ、投稿本文のみをそのまま出力する（前後に解説をつけない）。複数パターンで書き分けた候補を求められた場合は、パターン名を見出しにして2〜3案を並べる。文字数制限（Xの140字/全角制限など）を指定された場合はその制限内に収める。
