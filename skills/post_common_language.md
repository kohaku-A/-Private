# 共通言語を作るポストの知識

出典：ポスト作成テンプレ教材「売上につながるポスト7つの要素」の⑦「共通言語を作る」を掘り下げた画像2枚（コンセプト解説1枚＋メカニズム解説1枚）を、今後ポストを書く際に再利用できる知識として整理したもの。

この資料は`skills/post_principles.md`で挙げた7要素のうち7番目（最後）「共通言語を作る」の詳細版にあたる。他の要素は`skills/post_principles.md`・`skills/post_positioning.md`・`skills/post_engagement.md`・`skills/post_cta.md`・`skills/post_realtime.md`・`skills/post_my_concept.md`・`skills/post_hook.md`を参照。

## 目的

**「読者と自分が共通で理解できるワードを作る」**こと。**「売れてる発信者は、必ず共通言語を作っている」**という前提に立つ。共通言語を作ることで読者のマインドシェアを獲得し、単なるフォロワーからファンへの転換を促す。

## 構成

**よくある共通言語のカテゴリ**

- **語尾**：例「〜でふ。」（少しアホそうな印象を与える等、キャラクター性を出す）
- **YOUを表すことば**：例「貴様ら」（二人称の独自表現）
- **共通の絵文字**：複数の絵文字を組み合わせて固定的に使う
- **最重要な概念：Myコンセプト**：`skills/post_my_concept.md`で扱った自分の価値観そのものが、最も重要な共通言語になる

**メカニズム（なぜ機能するのか）**

- 人間は好きな人の使う言葉を無意識に真似てしまう傾向にある。
- 読者が自分と同じワードを使うようになると、それは**ファンがついてきている証拠**。
- **共通言語ができている＝マインドシェアが取れている**——つまり、読者の思考の中に自分（発信者）の存在が定着している状態を意味する。

## 書き方

- **複数のカテゴリで独自の言い回しを設計する**：語尾・二人称・絵文字など、複数の要素を組み合わせて一貫したキャラクターを作る。
- **同じワードを繰り返しポストに入れる**：「自分なりにワードを作って何度も何度もポストに入れてみよう」という原則の通り、1回では定着しない。反復によって初めて共通言語として機能する。
- **Myコンセプトに紐づくワードを核にする**：単なる語呂合わせではなく、`identity/my_offer.md`の提供する変化や`skills/my_position.md`の価値観と結びついたワードにすると、共通言語自体がブランドの一貫性を強化する。
- **読者が同じワードを使い始めたら積極的に反応する**：リプライ等で拾って反応すると、共通言語の定着とファン化がさらに強化される。

## テンプレート

### 共通言語設計シート
```
語尾：（例：印象を決める独自の語尾）
YOUを表す言葉：（例：読者を指す独自の呼び方）
共通の絵文字：（3〜5個程度に絞って固定化する）
Myコンセプトに紐づくキーワード：
（identity/my_offer.mdの提供する変化、skills/my_position.mdの価値観から抽出する）
```

## 注意点

- **教材由来の具体例をそのまま流用しない**：「〜でふ」「貴様ら」は元アカウント固有のキャラクターに基づくものであり、このプロジェクトでは`skills/values.md`で定義した独自の語尾・絵文字ルールに置き換えて使う。
- **共通言語は一貫性が命**：頻繁に変えると定着しない。一度決めたら継続して使う。
- **読者の模倣を揶揄しない**：読者が真似て使い始めたことを馬鹿にするような反応をすると、せっかくの親近感が損なわれる。
- **`identity/my_offer.md`・`skills/my_position.md`・`skills/values.md`を踏まえる場合**：`skills/values.md`で定義した絵文字ルール（☕️🌙💤👀🔥✍️📌🙃☺️🙂‍↕️等）と文体ルール（「〜と思ってる」「〜なんよね」等の語尾）は、すでにこのプロジェクトの共通言語として設計済みである。今後はこれを一貫して使い続けることそのものが、この技法の実践になる。
