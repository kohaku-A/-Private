# 行動させるポストの知識（行動トリガー）

出典：ポスト作成テンプレ教材「エンゲージメントをとるポスト」の補足POINT「行動させるポスト」の画像2枚（行動トリガーの解説1枚＋実例注釈2種）を、今後ポストを書く際に再利用できる知識として整理したもの。

この資料は`skills/post_engagement.md`（`skills/post_principles.md`の7要素のうち2番目「エンゲージメントをとる要素をいれる」）をさらに深掘りし、**読者が実際に行動する心理的な仕組み（行動トリガー）**に焦点を当てたもの。投稿を書く際は両方のファイルを併せて参照する。

## 目的

**「読者に行動させるには、何かしらの"理由"が必要」**という前提に立ち、行動を引き出す具体的な心理的トリガーを使い分けることで、エンゲージメントを継続的に獲得すること。日常的に反応を取ると、読者が勝手に反応してくれるようになる、という習慣化の効果も狙う。

## 構成

**5つの行動トリガー**

1. **発信者から認知を得られる**：反応すると「個」として認識される、という報酬（アイコンを覚えてもらえる等）。
2. **反応する人＝成功する人というラベリングをする**：反応することが望ましいアイデンティティと結びつく、というフレーミング。
3. **リプくれた人にDMで教える**：直接的な報酬（限定情報の提供）。
4. **いいねが多ければ公開する**：報酬の可能性（条件付き公開）。
5. **いつもリプしてるからリプする**：習慣化。

実例では、これらのトリガーが具体的に次のように使われている。

- **いいねを促す**：「〇〇な人はいいねで教えて！」というシンプルな行動喚起。
- **行動の理由を示す（トリガー1の実演）**：「いつもいいねくれるみんな、しっかりアイコン覚えてるからね〜」——反応すれば認知されるという理由を明示する。
- **リプしやすい質問をする**：「ONE PIECEのキャラやったら誰が好き？」のように、答えやすい具体的なお題を与えることでリプのハードルを下げる。
- **報酬の可能性を示す（トリガー4の実演）**：「需要あれば"いいね"ください！いいね多ければ〇〇の情報をバンバン出していきます」。

締めの重要な原則：**「リプ内容を決めてあげると読者が反応しやすくなる！」**——抽象的な問いかけではなく、具体的なお題を用意することが鍵になる。

## 書き方

- **行動を促す前に「なぜ反応すべきか」の理由を必ず添える**：理由がないと人は反応しない、という前提を常に意識する。
- **5つのトリガーから文脈に合うものを1〜2個選ぶ**：全部を1投稿に詰め込まない。
- **認知トリガーは実際に継続して使う**：「アイコン覚えてるからね」は、実際に覚えて対応し続けることで初めて信憑性が保たれる。
- **リプを取りたい場合は具体的で答えやすいお題を用意する**：「意見を聞かせて」のような抽象的な問いより、「ONE PIECEのキャラで誰が好き？」のような具体的なお題の方が反応しやすい。
- **条件付き報酬型（トリガー4）は約束を守る前提で使う**：「いいねが多ければ公開する」と言った以上、条件達成時には実際に公開する。
- **習慣化を狙う場合は同じ形式のCTAを継続して使う**：フォロワーが考えずに反応できる状態を作る。

## テンプレート

### 認知トリガー型テンプレート
```
[本題の投稿内容]

「[条件]」って人はいつも通り"いいね"で教えて！

いつも[反応]くれるみんな、
しっかりアイコン覚えてるからね〜

ちなみに…
[答えやすい具体的な質問]？

みんなのこともっと知りたいから、
その理由も教えてくれると嬉しい
```

### 報酬の可能性型テンプレート
```
[専門分野]の[トピック]を解説したポスト需要ありますか？

需要あれば"いいね"ください！

いいね多ければ[専門分野]の情報をバンバン出していきます
```

## 注意点

- **条件付き報酬の約束は必ず守る**：「いいねが多ければ公開する」と言って条件が達成されたのに公開しないと、信頼を損ない、次回以降このトリガーが機能しなくなる。
- **リプ用のお題は本題との関連性を保つ**：本題と無関係すぎるお題（雑談的な質問等）を多用すると、`skills/post_principles.md`の「Myコンセプトを反映する」要素とのバランスが崩れる。関連性の薄いお題を使う場合は頻度を抑える。
- **`skills/post_engagement.md`とセットで参照する**：本ファイルは行動トリガーの心理的な仕組みに特化しており、CTAの型そのもの（DM誘導ファネル等）は`skills/post_engagement.md`を参照する。
- **`identity/my_offer.md`・`skills/my_position.md`・`skills/values.md`を踏まえる場合**：`skills/values.md`の落ち着いたトーンでも、答えやすい質問でリプを促す技法自体は自然な会話の延長として違和感なく使える。ただし「アイコンと名前を覚えてます」といった発言は、実際に覚えている場合にのみ誠実に使う。
