# 冒頭で興味づけするポストの知識

出典：ポスト作成テンプレ教材「売上につながるポスト7つの要素」の⑥「冒頭で興味づけする」を掘り下げた画像3枚（コンセプト解説1枚＋技法別実例2枚）を、今後ポストを書く際に再利用できる知識として整理したもの。

この資料は`skills/post_principles.md`で挙げた7要素のうち6番目「一文目で惹きつける」の詳細版にあたる。他の要素（ポジション、エンゲージメント、導線、リアルタイム性、Myコンセプト、共通言語）は`skills/post_principles.md`・`skills/post_positioning.md`・`skills/post_engagement.md`・`skills/post_cta.md`・`skills/post_realtime.md`・`skills/post_my_concept.md`を参照。

## 目的

**「強く興味づけできる言葉を選ぶ」**こと。**「ポストの冒頭＝記事タイトル」**という意識を持ち、冒頭の一文で読者が続きを読みたくなる状態を作る。SNSでは冒頭の数秒で読むか読み流すかが決まるため、この部分に最も力を注ぐ必要がある。

## 構成

冒頭で興味づけする技法は8つある。

1. **一般常識を破壊する**：市場の常識を否定する。
2. **強いワードを使う**：衝撃・絶望・ガチ泣き・オワコンなど、感情の振れ幅が大きい言葉を使う。
3. **カギかっこを使う**：読者の気持ちを代弁する。
4. **メリットや実績をいれる**：読むメリットが明確なワードを使う。
5. **問題提起する**：読者に質問を投げかける。
6. **一文目からストーリー**：5W1Hを描写することで物語を動かす。
7. **損失回避を刺激する**：知らないと損失があるような表現を使う。
8. **ターゲティングする**：ターゲットにぎくりとさせる言葉を使う。

各技法の実例は次の通り。

| 技法 | 実例 |
|---|---|
| 一般常識を破壊する | 「なんか最近ってSNS伸びてる人が美徳とされてるけど、伸びてるよりもちゃんと収益に繋がってるか？の方がよっぽど大事」 |
| 強いワードを使う | 「【40代男性、ガチ泣き…】」 |
| カギかっこを使う | 「「Xだけで稼げるってほんと…？」「コンテンツ販売って怪しくね…??」」 |
| メリットや実績をいれる | 「作業0時間で日給12万円😭」 |
| 問題提起する | 「そもそもさ、なんでみんなビジネス系で戦ってんの？」 |
| 一文目からストーリー | 「どうしても仕事に行きたくなくてズル休みした2年前の今日。」 |
| 損失回避を刺激する | 「外注化に潜む落とし穴」 |
| ターゲティングする | 「あの…「実績がない」と悩んでる人…。」 |

## 書き方

- **冒頭を「記事タイトル」として書く**：何が書いてあるか一瞬で伝わり、かつ続きが気になる一文にする。
- **一般常識を破壊する**：世間の常識・美徳とされていることをあえて否定する切り口を使う（`skills/problem_post.md`の仮想敵批判と接続する）。
- **強いワードは頻度を絞って使う**：感情の振れ幅が大きい言葉ほど効果的だが、多用すると誇大な印象になる。
- **カギかっこで読者の心の声を代弁する**：読者が実際に思っていそうなセリフをそのまま書く（`skills/problem_post.md`の「問題点の内的独白」と同じ技法）。
- **メリット・実績は具体的な数字や条件で示す**：「作業0時間で」のような条件を入れると目を引く。
- **問題提起は読者に直接問いかける**：「なんで〇〇してんの？」のように、読者自身に矢印を向ける。
- **一文目からストーリーは5W1Hのいずれかを具体的に描写する**：情景が浮かぶ書き出しにすると読者を引き込みやすい。
- **損失回避は読者がまだ気づいていないリスクを匂わせる**：「〇〇に潜む落とし穴」のような表現を使う。
- **ターゲティングは特定の読者像を名指しする**：「あの…〇〇と悩んでる人…」のように、「自分のことだ」と思わせる。

## テンプレート

### 技法別の基本フォーマット
```
[一般常識を破壊する]
なんか最近って[世間の常識]が美徳とされてるけど、
[本質的な指標]の方がよっぽど大事。

[強いワードを使う]
【[属性]、[強い感情ワード]…】

[カギかっこを使う]
「[読者の心の声1]」
「[読者の心の声2]」
とか言ってる人、マジでもったいないんだけど。

[メリットや実績をいれる]
[条件]で[具体的な数字・成果]

[問題提起する]
そもそもさ、なんで[読者の行動]してんの？

[一文目からストーリー]
[時間・場所・状況]、[印象的な出来事]。

[損失回避を刺激する]
[テーマ]に潜む落とし穴

[ターゲティングする]
あの…
「[読者の悩み]」と悩んでる人…。
```

## 注意点

- **一般常識を破壊する際は他者を否定しすぎない**：`skills/problem_post.md`の仮想敵批判の注意点（個人攻撃にしない、賛否両論の前提で使う）がそのまま当てはまる。
- **強いワード・損失回避を刺激するワードは扇動的になりすぎないよう注意する**：読者を見下す・煽るような表現（例：「貴様はおバカチンなのですか？」）は、`skills/my_position.md`が否定する「読者を利用してもいい」という価値観に近づくリスクがあるため、このプロジェクトでは使わない。
- **カギかっこで代弁する声は実際の読者像に基づく**：的外れな代弁は共感を得られず逆効果になる。
- **ターゲティングは不安を煽りすぎない**：「ぎくりとさせる」のが目的であり、恐怖を煽ることが目的ではない。
- **`identity/my_offer.md`・`skills/my_position.md`・`skills/values.md`を踏まえる場合**：`skills/values.md`の「絶対に避ける方向」（熱血すぎる、イキリ、テンション芸）と、強いワード・煽り気味の代弁表現は相性が悪い。このプロジェクトで使う際は、技法のロジック（常識否定・代弁・問いかけ・ストーリー・損失回避・ターゲティング）は活用しつつ、表現は`skills/values.md`の落ち着いたトーンに翻訳して使う。
