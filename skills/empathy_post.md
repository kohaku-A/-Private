# 共感を得るポストの知識

出典：ポスト作成テンプレ教材「Type05：共感を得るポスト」の画像5枚（コンセプト解説1枚＋構成解説1枚＋過去を語る技法の解説1枚＋実例注釈2枚）を、今後ポストを書く際に再利用できる知識として整理したもの。

## 目的

**「情報にはファンがつかない」**という前提に立ち、自分の考えや過去に読者を共感させることでファン化することが目的。単なる無機質な情報発信は、他の発信者の情報と比較され、埋もれていく。一方、自分の過去や理念に共感が生まれると「〇〇さんだから」という理由で選ばれるようになり、比較から逃れられるため発信そのものが楽になり、高単価でも売れやすくなる。

## 構成

共感を得る技法は3つある。

1. **過去を語る**：過去の"普通だった"自分の生活や感覚を語ることで共感を得る。
2. **自分の発信理念を語る**：なぜ発信しているのか、何を大事にしているのかを語る。
3. **向上心を見せる**：現状に満足せず学び続けている姿勢を見せる。

このうち「過去を語る」は特に重要度が高く、次のような**極めて具体的で生活感のあるディテール**を使うことがポイントになる。

- 会社員をしていて毎日1時間かけて通勤した
- YouTubeを始めて動画を撮ったけど、再生数がごく少なく1本でやめた
- 毎日いいねやリプをしてフォロワーを増やしたけど1円も稼げなかった
- 貯金額が少なくて親にも友達にも言えなかった
- たまに安い外食をするのがささやかな楽しみだった

これはType04（再現性を伝えるポスト）の「才能がない・時間がないよ…」といった**抽象的な言い訳フレーズ**とは異なる。Type04は「読者と同じ弱さを持っていた」ことを示して再現性の壁を崩すのが目的だが、Type05は「読者と同じ普通の生活を送っていた」ことを示して**親近感・共感**を作るのが目的であり、使うディテールの粒度も具体的な生活描写に寄る。

実例を分解すると、次の流れで構成されている。

1. **過去の平凡さ・失敗談**：複数の挫折エピソードを立て続けに列挙する。
2. **変化を伝える**：今のことに出会った経緯・きっかけとなった転機を語る（1回で終わらせず、複数回挟むこともある）。
3. **理想の状態**：今の充実した生活を、金銭面だけでなく日常の具体的な描写で見せる。
4. **反応をとる**：読者の感情に軽く乗せる形でCTA（いいね・フォロー等）を添えて締める。

## 書き方

- **過去のディテールは固有名詞・数字を入れて具体化する**：「サイゼ」「Uber eats」「YouTube」のような固有名詞や、「10万円を切った貯金額」「6回しか再生されなかった」のような具体的な数字を入れると、"あるある感"が増して共感されやすい。
- **複数の失敗エピソードを畳みかけるように列挙する**：1つの失敗だけでなく、「〇〇に挑戦→挫折」を2〜3回繰り返して見せると、「この人も普通に人間くさい」という印象が強まる。
- **「変化を伝える」は投稿の中で複数回挟んでよい**：転機となった出来事を1箇所にまとめず、「きっかけ」と「その後の具体的な反応（購入通知が来た等）」のように段階的に描くと、読者が転機を追体験しやすい。
- **理想の状態は金銭的実績だけでなく日常の充実を交える**：「ペットに貢げる」「大切な人との時間に投資できる」のような生活面の描写を交えると、共感ベースの憧れに繋がりやすい。
- **締めは読者の感情に軽く乗せてCTAを添える**：「やったるでぇ！って気合い入った方はいいね」のように、読者の内的な高まりをそのままアクションに繋げる言い回しを使う。

## テンプレート

### 基本テンプレート（過去の平凡さ→変化→理想の状態→反応をとる）
```
何をやってもうまくいかなかった私が、
初めて自分の力で[成果]を出せた唯一の[分野]

私はいままで[挑戦1]、[挑戦2]、[挑戦3]といろんな[分野]に挑戦し、
その挑戦の数だけ挫折を味わった。

「[挑戦1]になろう！」
そう思って[具体的な行動]したものの
[具体的な失敗の描写]

「[挑戦2]で成功してやる！」
と決意し取り組むも
[具体的な失敗の描写]

そんな私が唯一続けられたのが、この[今のこと]なんよね。

[今のことに出会った経緯・きっかけ]

[転機となった出来事、その後の変化]

その結果、[理想の状態を具体的な生活描写で]

[反応を促すCTA]
```

### 共感の材料集めテンプレート（過去の"普通"を語る版）
```
過去の自分の"普通"だった生活・感覚を書き出すなら

・[通勤・仕事に関する具体的なエピソード]
・[挑戦したが結果が出なかった具体的なエピソード]
・[努力したが報われなかった具体的なエピソード]
・[お金にまつわる具体的なエピソード]
・[ささやかな楽しみだったこと]

これらをそのまま投稿の冒頭に並べると、
読者が「わかる」と共感しやすい下地になる。
```

## 注意点

- **過去のエピソードは実際の経験に基づくこと**：捏造・誇張した「あるある」は不自然さが伝わりやすく、共感どころか不信感につながる。
- **Type04の「言い訳フレーズ集」と混同しない**：Type05の「過去を語る」は再現性の壁を崩すためではなく、共感・親近感を作るための具体的な生活ディテールが中心であり、目的も表現の粒度も異なる（詳細は`skills/reproducibility_post.md`を参照）。
- **「情報にはファンがつかない」はノウハウ系投稿の否定ではない**：共感ポストとノウハウ・Tips系の投稿は役割が異なる。`skills/content-seller-post-writer/`の5パターンと組み合わせてバランスよく使う。
- **理想の状態を語る際、実績を誇張しない**：`skills/change_post.md`の注意点と同様、数字の誇張は信頼を損なう。
- **`identity/my_offer.md`・`skills/my_position.md`・`skills/values.md`を踏まえる場合**：共感を得るための過去語りは、`skills/values.md`の「努力アピールにしない」「現実として普通にキツかったという温度感で書く」というルールと相性がよい（Type05自体が本質的に等身大の共感を狙う技法のため）。軽いユーモア（「たまに安い外食が楽しみだった」等）は`skills/values.md`の「少し力の抜けたリアルでクスッとさせる」方向性で使うとよい。一方、実績金額の強調は`skills/my_position.md`の「フォロワー数やインプ数の大きさで信頼を得ようとしない」という価値観と衝突しやすいため、使う場合は数字よりも過去のエピソードの具体性・生活感を主役にする。
