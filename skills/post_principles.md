# 売上につながるポスト作成の共通原則

出典：ポスト作成テンプレ教材「意識するだけ売上UP！ポスト作成のコツ」の画像4枚（セクション扉1枚＋Type01〜07の位置づけ解説1枚＋次セクションへの導入1枚＋7要素のリスト1枚）を、今後ポストを書く際に再利用できる知識として整理したもの。

## このファイルの位置づけ

これまで整理してきた`skills/change_post.md`（変化を見せる）、`skills/problem_post.md`（問題点を指摘する）、`skills/recommended_method_post.md`（推奨手段を伝える）、`skills/reproducibility_post.md`（再現性を伝える）、`skills/empathy_post.md`（共感を得る）、`skills/action_post.md`（行動の重要性を説く）、`skills/self_investment_post.md`（自己投資の重要性を説く）は、教材内でType01〜07として順に紹介されてきた**投稿の型（切り口）**である。

教材はこれらの7つの型について、**「X運用の知識がある人は、基本これをおさえて運用している」＝できて当然の基礎知識**と位置づけている。その上で、ライバルと差別化し売上をアップさせるためには、**「どうやってこの7つの型を肉付けしてポストを作るか」が圧倒的に大事**だとしている。

`skills/post_principles.md`（本ファイル）は、その"肉付け"にあたる**投稿タイプを問わず共通して意識すべき7つの要素**を扱う。つまり、Type01〜07が「何を書くか（切り口）」を決める型であるのに対し、本ファイルは「どう仕上げるか（品質・差別化）」を決める横断的な原則にあたる。

## 目的

Type01〜07のどの型で投稿を書く場合でも、次の7要素を意識して肉付けすることで、単なる基礎レベルの投稿から、差別化され売上につながる投稿へと引き上げることが目的。

## 構成

**売上につながるポスト7つの要素**

1. ポジションをとるポストをする
2. エンゲージメントをとる要素をいれる
3. 導線に流す要素をいれる
4. ポストにリアルタイム性をだす
5. Myコンセプトを反映する
6. 一文目で惹きつける
7. 共通言語を作る

※教材にはこの7要素それぞれを詳しく解説する個別スライドは含まれていなかった。以下の「書き方」は、各要素の趣旨を、これまで整理した他の`skills/`ファイルの内容と照らし合わせて解釈・接続したものである。

## 書き方

1. **ポジションをとるポストをする**：当たり障りのない中立的な発信ではなく、明確な立場を取る。`skills/my_position.md`で定義した「押し出す価値観・否定する価値観」を軸に、賛否が分かれることを恐れずに主張する。`skills/problem_post.md`の仮想敵批判はこの具体的な技法の1つ。
2. **エンゲージメントをとる要素をいれる**：問いかけ、いいね・リプ・引用RTを促すCTAなど、読者の反応を引き出す仕掛けを入れる。各Typeファイルで扱った「反応をとる」パターンを、どのポストにも最低1つは意識的に組み込む。
3. **導線に流す要素をいれる**：固定ポストへの誘導、次の投稿への引き、リスト登録への流れなど、読者をアカウント内の資産（固定ポスト・リスト等）に流す要素を入れる。`skills/recommended_method_post.md`の導線誘導、`skills/my_position.md`の「リストを取得して資産化する発信」という価値観と接続する。
4. **ポストにリアルタイム性をだす**：「今まさに」取り組んでいること、投稿時刻や季節・出来事に紐づいた内容にする。`skills/empathy_post.md`の「向上心を見せる」技法（挑戦の過程をそのまま発信する）と直結する。
5. **Myコンセプトを反映する**：すべての投稿が`identity/my_offer.md`で定義したターゲット読者・提供する変化、`skills/my_position.md`の価値観からブレていないか確認する。1投稿ごとに「これはMyコンセプトのどの部分と繋がっているか」を意識する。
6. **一文目で惹きつける**：冒頭の一文で読者の目を止めるフックを入れる。`skills/empathy_post.md`の「矛盾で興味づけ」、`skills/problem_post.md`の問題点の提示など、各Typeファイルのオープニング技法をここに集約して使う。
7. **共通言語を作る**：独自の言い回し・略語・絵文字ルールを繰り返し使うことで、フォロワーとの一体感やアカウント固有の文化を作る。`skills/values.md`で定義した口調・絵文字ルールがこれに相当する。

## テンプレート

投稿を書き終えたときの、7要素チェックリストとして使う。

```
このポストは：
1. ポジション：どんな立場を取っている？（skills/my_position.md参照）
2. エンゲージメント：どんな反応を引き出す仕掛けがある？
3. 導線：どこに読者を流す？
4. リアルタイム性：今この瞬間ならではの要素はある？
5. Myコンセプト：identity/my_offer.mdの「提供する変化」と繋がっている？
6. 一文目：最初の一文で読者の目を止められる？
7. 共通言語：このアカウントらしい言い回し・絵文字（skills/values.md）は使えている？
```

## 注意点

- **7要素を毎回すべて盛り込む必要はない**：詰め込みすぎるとどのType（01〜07）の投稿でも冗長・不自然になる。投稿の目的に応じて2〜3個を意識的に強化する方が実用的。
- **「ポジションをとる」は賛否両論のリスクを伴う**：`skills/problem_post.md`の仮想敵批判の注意点（賛否両論を呼ぶ前提で使う、個人攻撃にしない）がそのまま当てはまる。
- **「共通言語を作る」は`skills/values.md`と矛盾しないようにする**：元教材由来の言い回し（「〇〇垢」等）をそのまま踏襲するのではなく、`skills/values.md`で定義したこのプロジェクト独自の語彙・絵文字ルールに置き換えて使う。
- **単体では使わない**：本ファイルはType01〜07（各投稿タイプ固有の`skills/`ファイル）を補完する横断的原則であり、実際の投稿作成では、まずTypeを1つ選び、その上でこの7要素を意識して肉付けする、という2段階の使い方をする。
